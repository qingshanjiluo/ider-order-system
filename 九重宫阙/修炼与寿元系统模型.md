## 一、三条公理（设计不变量，任何改动都不得违反）

```
A1  时间是唯一不可再生资源：现实 24h = 游戏 10 年，不可购买、不可暂停、不可回溯。
A2  寿元与境界无关：境界只解锁"能力与资格"，绝不平白增加寿命。
    寿元是"可被折损、也可被主动燃烧"的生命预算；耗尽即坐化转世。唯一永生 = 飞升。
A3  经验 = 修行时间 × 修炼速度；瓶颈/突破是"质变闸门"，速度再快也不能绕过。
    折寿换速 = 把未来的时间预算兑换成当前速度，是合法且被鼓励的赌博。
```
**推论**：一世约 10 现实日（100 游戏年）。因此**单世注定走不完全程**，长线乐趣必须来自
转世传承（见蓝图 §6.1 传承点/道行），而不是靠"活得越来越久"。这是本作区别于普通挂机游戏的核心。

```
V = V0(境界) × Q(资质) × G(功法) × E(契合) × D(环境) × M(闭关) × P(百艺) × S(状态) × B(燃寿)
```

## 三、寿元账本（A2 的落地）

### 3.1 出生与上限
```
出生寿元 = 95 + 体质/20 + rand(−5,+15)          → 实际 90~115 年，均值 ~100
寿元硬顶 = 200 年（延寿总收益封顶 +100 年）      → 飞升后超脱（保留 gameTime.isAscended）
境界加成 = 0（删除 LIFESPAN_BY_REALM 的"境界给命"语义，仅保留为"突破才能采到高级延寿药"的间接路径）
```
### 3.2 扣减（负向，全部走 `gameTime.subtractLifespan`）
| 来源 | 数值 | 触发点 |
|---|---|---|
| **突破失败** | 第 n 次连败：`5 + 3(n−1)` 年，单次封顶 20 年；心魔 +1 层 | `realm.breakthrough` 失败分支 |
| **受伤/重伤** | 轻伤1 / 重伤2–8 / 道伤(濒死)15 | `injury.js`（第74行已在查 `shouldPassAway`，加一条扣减调用） |

| **功法副作用** | 邪功 0.5~2 年/游戏年；燃寿功见 §3.3 | 功法表 `lifespan_cost_per_year` |

| 途径 | 数值 | 说明 |
|---|---|---|
| 延寿丹四档 | +3 / +8 / +20 / +45 | 丹毒 +1/+2/+3/+5，边际递减（超过剩余寿元50%部分减半） |
| 灵植/天材地宝 | 万年血参+3、九转灵芝+8、仙灵草+25 | **每类每世限用次数**（3/2/1）→ 防囤积永生 |
| 正道长生功 | +0.2 年/游戏年 | 代价：`V × 0.8`（慢修），构成"要命还是要道"的抉择 |

### 3.4 枯竭曲线（让"濒死"成为可玩的赌局）
```
剩余寿元 < 20% → V×0.7，突破 P−10%（油尽灯枯）
剩余寿元 < 5%  → 心魔层 +1/游戏年，且自动弹「立遗嘱/转世准备」UI
```
**设计目的**：末期玩家必然面对"燃寿豪赌冲一境界"或"从容坐化留资源给后世"，这是本作最有戏味的时刻，必须有明确 UI 与传记记录。

## 四、闭关·瓶颈·熟练度·突破的关系链

```
资质Q ──┐
功法G ──┤（契合E、环境D 调制）                ┌── 契机（材料/丹药/悟道）
百艺P ──┤→→→  V 修炼速度 →→→ 修为积累 ─→→→  瓶颈闸门 ─→→→ 突破判定 P ──┬→ 成功：境界+1，连败清零，
行气熟练 ┘                          ↑                        │          └→ 失败：折寿+心魔+修为回落10%
                                    │                        │
             闭关M（提速/机会成本） ─┘      寿元 ◄───────────┘（失败代价直接扣生命预算）
                                   
寿元耗尽 → 坐化转世 → 道行/传承点 → 下一世 Q/功法/洞府 起点更高（跨世正反馈）
```
**四者分工（不得互相替代）**
- **修炼（速度）**：决定"多久填满当前境界"。任何瓶颈都**不能**靠堆速度解决。
- **资质（上限）**：决定速度乘区天花板 + 契合可用性 + 出生寿元。**转世可微幅养成**（血脉/洗髓），是唯一跨世属性。
- **熟练度（三条独立线，共用 100×lv^1.6 曲线）**
  ① **行气**（全局）→ 速度乘区 P、丹毒抗性；
  ② **功法**（单本）→ 该功法 G 满层、契合 E 从 1.0 抬到 1.35、解锁"功法契机"（圆满可免一次瓶颈材料）；
  ③ **百艺**（炼丹/炼器/画符/阵法/种植）→ 决定"契机物品与延寿丹"的**可得性与品质**，即间接决定一世能突破几次。
  > 这条链是"生产系统喂成长系统"的骨架，绝不能把百艺加成直接塞进 V（否则生活玩法失去意义）。
- **瓶颈（闸门）**：两层
  小瓶颈（境界内 `前期/中期/后期/半步`，`realm.js` 已有 stages）→ 需"契机"，非纯经验；
  大瓶颈（半步→下一境界）→ 需契机 + 突破判定。
- **突破（赌博）**：概率 + 失败代价（寿元/心魔/修为回落）。

### 4.1 突破判定定案（替换 `realm.js:29`）
```
P = clamp( base[境界] − 5×心魔层 − 3×连败 + 契机加成 + 天道庇护 + 阵法/灵脉加成, 5, 95 )
base: 炼气90 筑基80 金丹70 元婴60 化神50 炼虚42 合体35 大乘28 渡劫20 飞升12
契机加成：破境丹+15 | 丹药档+5~15 | 聚灵阵+8 | 灵脉 lv×2 | 功法圆满+10 | 悟道事件+20
天道庇护：连败≥3 后每次 +6（保底，防弃坑）
失败结算：修为 −10%（不降境界）| 心魔+1 | 折寿 5+3(n−1) | 3日内"道基受损" P−10 且 V×0.85
```

### 4.2 闭关档位（速度×机会成本，非寿元成本）
| 档 | V | 代价 |
|---|---|---|
| 不入关 | ×1.0 | 可采集/战斗/交易/社交 |
| 心斋 | ×1.2 | 离线结算失效（须在线） |
| 坐忘 | ×1.6 | 禁采集与战斗，其他可用 |
| 枯荣 | ×2.2 | 禁采集/战斗/交易；每5年心魔+1 |
| 入定 | ×3.0 | 全禁；每3年心魔+1；出关后"动凡心" V×0.85 持续3年 |
> 闭关**不扣寿元**（时间本来就流逝），扣的是"这段时间不能做的事"——这才是 A1 的干净表达；
> 真正消耗寿元的通道只有 §3.2（其中"燃寿"是玩家主动、可量化、可 UI 滑杆的那一条）。

## 六、需你确认的 4 个数值/产品口径
1. **一世基准 100 游戏年 = 10 现实日**，延寿硬顶 200 年（20 现实日）——是否接受"单世必然走不完"？（我推荐接受，传承才是长线）
2. **突破不降境界、只折寿+回落修为**——是否改为更狠的"降一阶"？（我推荐不降，挂机游戏劝退成本高）
3. **燃寿换速**保留到几档？3 档最强 ×2.05，代价 1.6 年/单位（我推荐 3 档，且 UI 明示"预计 X 年后坐化"）。
4. **飞升是唯一永生**（渡劫成功=超脱寿数，现有 `isAscended` 语义保留）——是否要求飞升后仍有"仙界新章"进度轴？
