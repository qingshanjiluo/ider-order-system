## 一、四条公理

```
A1  时间唯一不可再生：现实 24h = 游戏 10 年，不可购买/暂停/回溯。
A2  寿元随境界增长：每突破一大境界，寿元上限立即增加 ΔL —— 这是"续命"的主通道，无替代品。
    反之，停在原境界不动，时钟会把你追上（坐化转世）。
A3  经验 = 修行时间 × 修炼速度；瓶颈/突破是质变闸门，速度再快也绕不过。
A4  寿元是可被折损、也可主动燃烧的真额度：突破失败、重伤、丹毒猛药、功法副作用、燃寿换速都扣它；
    延寿丹/灵植/宗门赏赐只是"补充通道"，永远无法替代境界增量。
```

**核心张力（本作的引擎）**：A2 + A4 让"突破"成为生死事件——
> 成功：立刻回补 ΔL（大幅回本）；失败：折寿 `5+3(n−1)` 年且无进账；
> 燃寿冲刺则是把 A4 的筹码押上赌桌，赌赢续命、赌输早死。
> 于是"要不要在油尽灯枯前搏一把金丹"成为玩家真正会记住的决策。

## 二、寿元结构（一个公式说清）

```
寿元上限 cap(realm) = L[realm] + bonus_years − penalty_years        （gameTime.effectiveLifespan 已是此式 ✓）
    L[realm]      境界额度（唯一由境界决定的项，突破时立涨）
    bonus_years   延寿丹/灵植/赏赐/机缘 累计（封顶 = 当前境界 L 的 30%）
    penalty_years 突破失败累进 + 重伤/道伤 + 丹毒猛药 + 功法副作用 + 主动燃寿 + 渡劫失败 累计
当前年龄 age = settleTime() 累计（含离线，100% 折算）
坐化条件 age ≥ cap → passAway()（既有实现 ✓，保留清单不动）
```
### 2.1 境界额度阶梯（重标定：L 由"现有 200→100万"压缩到与节奏匹配）
| 境界 | 旧 L | **新 L（额度）** | 突破立涨 ΔL | 现实日等值 |
|---|---|---|---|---|
| 凡人 | 100 | 60 | — | 6 天 |
| 炼气 | 200 | 90 | +30 | 9 天 |
| 筑基 | 500 | 220 | +130 | 22 天 |
| 金丹 | 1500 | 620 | +400 | 62 天 |
| 元婴 | 5000 | 1500 | +880 | 150 天 |
| 化神 | 2万 | 3200 | +1700 | — |
| 炼虚 | 5万 | 6200 | +3000 | — |
| 合体 | 10万 | 11000 | +4800 | — |
| 大乘 | 30万 | 19000 | +8000 | — |
| 渡劫 | 100万 | 30000 | +11000 | — |
| 飞升 | — | 超脱（保留 `isAscended`） | — | — |
> 压缩理由：旧 L（渡劫 100 万年 = 10 万现实日）等于**永不两脚**，"停滞会死"沦为空话；
> 新 L 使一世自然寿元**刚好略快于**修炼耗时，才有追赶感。L 全部进 `balance.js`，是可调项。

### 2.2 追赶校验（设计准则，不是估测）
```
定义：cumT(r) = 从出生修至境界 r 圆满所需累计游戏年 = Σ 需求/当世实际速度（由 sim 脚本反推）
铁律（写进校验器）：
  (1) cumT(r) < L(r)                    ∀r ≤ 元婴      → 前四境靠自然寿元可达（新手不被卡死）
  (2) L(r) − cumT(r+1) < 0              ∀r ≥ 元婴      → 元婴之后"必须经营寿元"才能前进
  (3) 目标余量比 (L−cumT)/L：炼气 >60% / 筑基 40~55% / 金丹 15~30% / 元婴 5~15% / 化神起为负
  (4) 单境界内折寿上限校验：连败 3 次 + 重伤 2 次 不得使 cap 低于 cumT(r)（否则玩家必死无疑→数值事故）
```
准则 (2)(3) 就是"停着就会死"的数学表达；**下轮以 `scripts/sim-balance.js` 跑实际 exp 需求/V 反推 cumT 并出表校准**（本轮先锁规则与阶梯，避免伪精确）。

### 2.3 枯竭与预警（让"追赶"可感知）
| 剩余 `cap−age` | 效果 | 呈现 |
|---|---|---|
| >40% | 无 | 仪表盘绿色 |
| <30% | 无惩罚，**开始催逼** | 传记"寿元将尽"提醒 + 建议延寿/闭关 |
| <15% | 突破 P−10 | 黄色警告、每日传记 |
| <5% | `V×0.7`、心魔 +1/游戏年 | **弹「立遗嘱 / 备转世 / 燃寿最后一搏」面板** |
| ≤0 | 坐化转世 | 传记终章 + 道行结算 |

## 四、寿元的增减通道（全部经 `addLifespanBonus` / `subtractLifespan`，已有函数）

### 4.1 增量（续命）
| 途径 | 数值 | 约束 |
|---|---|---|
| **境界突破（主通道）** | +ΔL（见 2.1） | 唯一不可封顶、不可重复刷的通道 |
| 延寿丹四档 | +3/+8/+20/+45 | `bonus_years` 总封顶 = L 的 30%；超 50% 剩余部分减半；丹毒 +1/+2/+3/+5 |
| 延寿灵植 | 血参+3 / 灵芝+8 / 仙灵草+25 | **每类每世限 3/2/1 次**（堵死囤积永生） |
| 正道长生功 | +0.2 年/游戏年 | 代价 `V×0.8`（要命还是要道的日常版） |
| 宗门赏赐 | +5（贡献 5000，每世 1 次） | 与宗门/贡献系统闭环 |
| 顿悟机缘 | +1~10（随机） | 写编年史 |

### 4.2 减损（折寿）
| 来源 | 数值 | 触发 |
|---|---|---|
| **突破失败** | `5+3(n−1)` 年，单次封顶 20；心魔+1 | `realm.breakthrough` 失败分支（新增） |
| 重伤 / 道伤 | 2–8 / 15 年 | `injury.js`（第 74 行附近已有 `shouldPassAway`，补 `subtractLifespan`） |
| 猛药·禁药 | 1–5 年 + 丹毒+1 | `pill-library` 新字段 `life_cost/toxicity` |
| 功法副作用 | 邪功 0.5–2 年/游戏年 | 功法表 `lifespan_cost_per_year` |
| **燃寿换速（主动）** | 1档 1年/次、2档 1.25、3档 1.6；回报 `+V×0.25×档系数` 修为 | 新端点，UI 滑杆 + 明示"预计 N 年后坐化" |
| 渡劫失败 | 20–60 年 | 蓝图 §6.3 |
| 油尽灯枯 | 心魔层数累加（间接降 V，不额外扣寿，避免死亡螺旋失控） | §2.3 |

> **守恒律**：`age += 游戏年流逝`（时钟），`cap = L + bonus − penalty`（账本）。
> 折寿是**动 cap**、不是动 age——这样"延寿"与"燃寿"都能被直观显示为同一条进度条上的正负项，
> 也让"突破立涨 ΔL"在 UI 上表现为进度条猛地拉长（极强的正反馈时刻）。

## 五、瓶颈·突破·熟练度·资质的分工（关系不变，仅重述）

```
资质Q ┐
功法G ┤（契合E·环境D 调制）        ┌ 契机(材料/丹药/悟道)
百艺P ┼→ V 速度 →→ 修为 →→ 瓶颈闸门 →→ 突破判定P ┬ 成功→境界+1 & **cap 立涨 ΔL**（续命）
行气熟练┘                        ↑              └ 失败→**折寿** + 心魔+1 + 修为回落10%
        闭关M（提速×机会成本）────┘                      │
                                              坐化 → 转世 → 道行/传承点 → 下一世 Q·功法·洞府更高
```
- **修炼（速度）** 只决定"多久填满当前境界"，**永远不能**买通瓶颈。
- **资质** 决定速度天花板 + 契合可用性 + 出生寿元（±）；转世可微幅养成（血脉/洗髓）——唯一跨世属性。
- **熟练度三线正交**：①行气＝全局速度 P + 丹毒抗性；②功法＝该功 G 满层 + 契合抬到1.35 + 圆满免一次契机；③百艺（丹/器/符/阵/植）＝决定**契机物品与延寿丹的可得性与品质**，故间接决定一世能续命几次、能赌几回。
  > 红线：不得把百艺加成直接塞进 V（否则生活玩法沦为数值）。
- **瓶颈两层**：境界内 `前期/中期/后期/半步`（`realm.js` stages 已有）需契机；大境界需契机 + 判定。
- **突破判定（替 `realm.js:29`）**
```
P = clamp( base[境界] − 5×心魔 − 3×连败 + 契机加成 + 天道庇护 + 阵法/灵脉, 5, 95 )
base: 炼气90 筑基80 金丹70 元婴60 化神50 炼虚42 合体35 大乘28 渡劫20 飞升12
契机：破境丹+15 | 丹药档+5~15 | 聚灵阵+8 | 灵脉lv×2 | 功法圆满+10 | 悟道+20
天道庇护：连败≥3 后每次 +6（防弃坑保底）
成功结算：境界+1 | 连败/道基清零 | **cap += ΔL（续命，传记高亮）**
失败结算：修为−10%（不降境界）| 心魔+1 | 折寿累进 | 3日内 道基受损 P−10 且 V×0.85
```

## 七、要你拍板的 3 项（v4 重列）
1. **新 L 阶梯**（凡人60 → 渡劫3万）等价于"一世自然寿元 6–30 现实日"，且**元婴起必须经营延寿**。是否接受这个难度？（我推荐接受：它才让"突破=续命"真正可感）
2. 时间流速 **24h = 10 游戏年** 保持不动？若你希望一世更短（更像"几世为人"），可改 24h = 30 年，代价是所有 L/ΔL 同步 ×3。（我推荐先跑 sim 再定）
3. **油尽灯枯时是否开放"燃寿最后一搏"一键**（自动把剩余寿元押上冲刺本次突破）？这是最有戏剧性的功能，但我建议加**二次确认 + 传记留痕**。（推荐做）
