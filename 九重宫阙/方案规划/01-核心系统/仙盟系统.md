## 仙盟战

### 仙盟战规则

| 规则 | 说明 |
|------|------|
| 参赛资格 | 仙盟等级6级以上 |
| 匹配机制 | 根据仙盟战力排名匹配 |
| 战斗形式 | **10v10组队战**（非实时对战） |
| 报名机制 | 每个成员报名，**盟主审批** |
| 比赛时间 | 每周六晚8点 |
| 胜利奖励 | 仙盟资源、领地、特殊buff |

### 仙盟战流程

| 阶段 | 说明 |
|------|------|
| 报名阶段 | 成员报名参战 |
| 审批阶段 | 盟主审批参赛成员（10人） |
| 战斗阶段 | 10v10组队战 |
| 结算阶段 | 根据胜负发放奖励 |

### 仙盟战奖励

| 胜负 | 奖励 |
|------|------|
| 胜利 | 仙盟资源、领地、特殊buff |
| 失败 | 仙盟资源 |
