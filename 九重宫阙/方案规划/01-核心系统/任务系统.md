## 任务规则

### 每日任务规则

| 规则 | 说明 |
|------|------|
| 刷新时间 | 每日0:00刷新 |
| 完成奖励 | 完成后立即发放 |
| 重置规则 | 每日只能完成1次 |

### 主线任务规则

| 规则 | 说明 |
|------|------|
| 解锁条件 | 完成前置任务 |
| 完成奖励 | 完成后立即发放 |
| 重置规则 | 不能重置 |

### 支线任务规则

| 规则 | 说明 |
|------|------|
| 解锁条件 | 达到一定等级 |
| 完成奖励 | 完成后立即发放 |
| 重置规则 | 不能重置 |

### 成就任务规则

| 规则 | 说明 |
|------|------|
| 解锁条件 | 达到一定条件 |
| 完成奖励 | 完成后领取 |
| 重置规则 | 不能重置 |
