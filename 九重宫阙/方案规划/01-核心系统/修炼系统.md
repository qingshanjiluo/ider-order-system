# 修炼系统

## 境界体系

### 境界划分（8大境界）

| 境界 | 等级范围 | 阶段 |
|------|----------|------|
| 炼气 | 1-10 | 前期→中期→后期 |
| 筑基 | 11-20 | 前期→中期→后期 |
| 金丹 | 21-30 | 前期→中期→后期 |
| 元婴 | 31-40 | 前期→中期→后期→半步 |
| 化神 | 41-50 | 前期→中期→后期→半步 |
| 渡劫 | 51-60 | 前期→中期→后期→半步 |
| 大乘 | 61-70 | 前期→中期→后期→半步 |
| 飞升 | 71+ | 前期→中期→后期→半步 |

### 突破条件

| 条件 | 说明 |
|------|------|
| 经验要求 | 满足升级经验 |
| 资质要求 | 资质达到突破要求 |
| 突破概率 | 根据综合因素计算 |

### 突破概率

| 因素 | 影响 |
|------|------|
| 基础概率 | 根据境界决定 |
| 资质加成 | 资质越高，概率越高 |
| 洞府加成 | 洞府内放置的阵法/灵植等辅助道具越多，概率越高 |
| 道具加成 | 使用道具提高概率 |
| 失败惩罚 | 累计失败次数越多，惩罚越重（见下表） |

---

## 突破机制

### 成功突破

| 结果 | 说明 |
|------|------|
| 境界提升 | 境界提升一个阶段 |
| 属性提升 | 属性大幅提升 |
| 解锁功能 | 解锁新功能 |

### 突破失败惩罚（累计总次数，不只是当前境界）

| 累计失败次数 | 惩罚内容 |
|--------------|----------|
| 1-3次 | 清除当前经验积累 |
| 4-5次 | 增加下次突破难度（降低基础突破概率） |
| 6-7次 | 降低资质1点 |
| 8次+ | 增加渡劫难度 + 突破难度提升 + 资质下降（累计总次数计算，逐次递增） |

### 渡劫战斗

| 项目 | 说明 |
|------|------|
| 触发条件 | 化神以上境界突破时触发 |
| 战斗内容 | 击败渡劫BOSS |
| 失败惩罚 | 同突破失败惩罚 + 可能身受重伤（temporarily debuff） |

## 洞府系统

洞府是**修炼辅助物品放置位置**，可放置多种辅助道具以提升修炼效率。

### 可放置物品类型

| 物品类型 | 说明 |
|----------|------|
| 阵法 | 提升修炼效率、增加突破概率 |
| 灵植 | 产出灵草、缓慢提供灵气 |
| 法器 | 提供属性加成 |
| 俘虏 | 特殊效果（如降低突破失败惩罚等） |
| 其他辅助道具 | 各类修炼辅助功能 |

### 洞府等级

| 等级 | 灵气浓度 | 修炼效率加成 | 可放置数量 |
|------|----------|--------------|------------|
| 普通洞府 | 100% | 无 | 2个 |
| 高级洞府 | 150% | +50% | 4个 |
| 顶级洞府 | 200% | +100% | 6个 |

### 洞府升级

| 项目 | 说明 |
|------|------|
| 升级材料 | 消耗灵石和材料 |
| 升级时间 | 根据等级决定 |
| 升级效果 | 提升灵气浓度、修炼效率和可放置物品数量 |

---

## 修炼速度

- 境界越高，升级所需经验越多（指数级增长）
- 修炼速度受以下因素影响：
  - 修炼功法品质
  - 洞府灵气浓度
  - 灵根资质
  - 洞府内阵法/灵植加成
  - 仙盟建筑加成
