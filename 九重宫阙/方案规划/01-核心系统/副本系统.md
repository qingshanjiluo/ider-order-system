# 副本系统

## 副本分类

### 三大副本类型

| 类型 | 说明 | 进入条件 |
|------|------|----------|
| 公共副本 | 所有玩家可进入 | 等级达到要求 |
| 宗门副本 | 仅本宗门成员可进入 | 加入宗门 + 等级达到要求 |
| 飞升副本 | 高阶副本，飞升后解锁 | 飞升境界 |

## 副本规则

### 进入规则

| 规则 | 说明 |
|------|------|
| 进入条件 | 等级达到要求 |
| 进入次数 | 每日有次数限制 |
| 组队要求 | **可选择是否组队**（单人/组队均可） |

### 战斗规则

| 规则 | 说明 |
|------|------|
| 战斗方式 | 自动战斗 |
| 战斗时间 | 不限制 |
| 胜利条件 | 击败所有敌人 |
| 失败条件 | 全部阵亡 |

### 评价规则（5星制）

| 评价 | 条件 | 奖励加成 |
|------|------|----------|
| 1星 | 通关 | 无 |
| 2星 | 无阵亡 | +20% |
| 3星 | 3分钟内通关 | +50% |
| 4星 | 1分钟内通关 | +100% |
| 5星 | 极限通关（特定条件） | +200% |

## 副本扫荡

### 扫荡规则

| 规则 | 说明 |
|------|------|
| 扫荡条件 | 达到对应星级后可扫荡 |
| 扫荡次数 | 每日有次数限制 |
| 扫荡消耗 | 消耗体力 |

### 扫荡收益

| 评价 | 扫荡奖励 |
|------|----------|
| 1星 | 基础奖励 |
| 2星 | +20%奖励 |
| 3星 | +50%奖励 |
| 4星 | +100%奖励 |
| 5星 | +200%奖励（最高级超阶） |

### 服内排名扫荡加成

| 服内排名 | 扫荡收益加成 |
|----------|--------------|
| 第1名 | +5阶扫荡收益 |
| 第2名 | +4阶扫荡收益 |
| 第3名 | +3阶扫荡收益 |
| 第4-10名 | +2阶扫荡收益 |
| 第11-50名 | +1阶扫荡收益 |
| 第51-100名 | 基础扫荡收益 |
| 第100名+ | 无额外加成 |
