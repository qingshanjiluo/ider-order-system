# 功法系统

## 功法分类

### 功法类型

| 类型 | 装备数量 | 说明 |
|------|----------|------|
| 修炼功法 | 1主修 + 1辅修 | 用于修炼，提升修炼速度和经验获取 |
| 战斗功法 | 2个（不分主副） | 用于战斗，提供技能和属性加成 |

### 修炼功法

| 位置 | 说明 |
|------|------|
| 主修功法 | 主要修炼功法，决定修炼速度和灵根方向 |
| 辅修功法 | 辅助修炼功法，提供额外属性加成 |

### 战斗功法

| 位置 | 说明 |
|------|------|
| 战斗功法1 | 第一个战斗功法，提供技能和攻击属性 |
| 战斗功法2 | 第二个战斗功法，提供技能和防御/辅助属性 |

## 功法品质

### 六阶品质体系

| 品质 | 细分 | 稀有度 | 属性倍率 |
|------|------|--------|----------|
| 黄阶 | 下品→中品→上品→极品 | 常见 | ×1.0 |
| 玄阶 | 下品→中品→上品→极品 | 少见 | ×1.5 |
| 地阶 | 下品→中品→上品→极品 | 稀有 | ×2.0 |
| 天阶 | 下品→中品→上品→极品 | 极稀有 | ×3.0 |
| 圣阶 | 下品→中品→上品→极品 | 传说 | ×5.0 |
| 仙阶 | 下品→中品→上品→极品 | 神话 | ×8.0 |

### 功法技能

| 规则 | 说明 |
|------|------|
| 技能数量 | 根据功法不同，**0-5个** |
| 技能类型 | 主动技能、被动技能、触发技能 |
| 技能学习 | 功法自带，无需额外学习 |

## 功法获取

### 获取方式

| 方式 | 说明 | 占比 |
|------|------|------|
| **宗门功法** | 主要获取方式 | 60% |
| 系统商店 | 为辅，购买功法 | 25% |
| 副本产出 | 最少，概率掉落 | 15% |

### 功法残集

| 残集 | 说明 |
|------|------|
| 功法残页 | 10个残页合成1本功法 |
| 功法碎片 | 10个碎片合成1个残页 |
| 功法书 | 直接获得完整功法 |

## 功法升级

### 升级规则

| 规则 | 说明 |
|------|------|
| 升级材料 | 消耗功法经验 |
| 升级上限 | 功法等级不能超过角色等级 |
| 升级成功率 | 100%成功 |

### 升级消耗

| 功法等级 | 升级消耗 |
|----------|----------|
| 1-10级 | 100功法经验/级 |
| 11-20级 | 200功法经验/级 |
| 21-30级 | 400功法经验/级 |
| 31-40级 | 800功法经验/级 |
| 41-50级 | 1600功法经验/级 |
