# 战斗系统

## 战斗规则

### 战斗方式

| 方式 | 说明 |
|------|------|
| 自动战斗（默认） | 系统自动控制角色战斗，玩家可随时干预 |
| 手动调整 | 支持手动调整功法释放顺序和优先级 |
| 异步对战 | 与AI控制的对手战斗（竞技场/PVP） |

### 战斗时间

| 类型 | 时间限制 |
|------|----------|
| 所有战斗 | **不限制时间**，直到一方全部阵亡 |

### 胜利条件

| 类型 | 胜利条件 |
|------|----------|
| PVE | 击败所有敌人 |
| PVP | 击败对手 |
| 仙盟战 | 击败对手仙盟 |

### 失败条件

| 类型 | 失败条件 |
|------|----------|
| PVE | 全部阵亡 |
| PVP | 全部阵亡 |
| 仙盟战 | 全部阵亡 |

## 技能系统（宗门流派体系）

### 技能来源

技能体系根据**各个宗门流派**制作，不同宗门拥有独特的技能树。

| 宗门流派 | 技能特色 |
|----------|----------|
| 青云剑宗 | 剑系技能，高攻击、高暴击 |
| 太虚道宫 | 道系技能，控制、减益为主 |
| 玄天魔门 | 魔系技能，吸血、持续伤害 |
| 佛门圣地 | 佛系技能，治疗、护盾、反伤 |
| 妖族部落 | 妖系技能，召唤、变身、群体攻击 |
| 散修联盟 | 混合技能，灵活多变 |

### 技能分类

| 类型 | 说明 |
|------|------|
| 主动技能 | 手动释放的技能（可设置自动释放优先级） |
| 被动技能 | 自动生效的技能 |
| 触发技能 | 满足条件触发的技能 |

### 技能配置

| 规则 | 说明 |
|------|------|
| 功法技能 | 每本功法携带0-5个技能（根据功法设定） |
| 技能栏 | 最多装备6个主动技能 |
| 优先级调整 | 可自由调整自动战斗中技能释放优先级 |

## 属性元素系统

### 基础属性

| 属性 | 说明 |
|------|------|
| 攻击 | 影响伤害输出 |
| 防御 | 影响受到伤害 |
| 生命 | 血量上限 |
| 速度 | 决定出手顺序 |
| 暴击 | 暴击概率 |
| 闪避 | 闪避概率 |
| 灵力 | 影响技能伤害加成 |

### 元素属性

| 元素 | 克制关系 |
|------|----------|
| 金 | 克木 |
| 木 | 克土 |
| 土 | 克水 |
| 水 | 克火 |
| 火 | 克金 |

### 灵石与灵根

| 项目 | 说明 |
|------|------|
| 灵根类型 | 金/木/水/火/土 单灵根或多灵根 |
| 特殊灵石 | 携带元素属性的灵石 |
| 灵石效果 | 使用对应元素的特殊灵石可提高该元素灵根的修炼速度 |
| 灵根影响 | 灵根决定可修炼的功法类型和技能效果 |

## 伤害计算

### 伤害公式（复杂版）

```
基础伤害 = (攻击力 × 技能系数 - 防御力 × 防御系数) × (1 + 暴击加成) × 元素克制系数 × 灵力加成

最终伤害 = 基础伤害 × (1 + 阵法加成) × (1 + 仙盟加成) × (1 - 闪避减免) × 随机浮动(0.95~1.05)
```

### 各系数说明

| 系数 | 公式 | 说明 |
|------|------|------|
| 防御系数 | 防御 / (防御 + 等级 × 50) | 等级越高，防御收益递减 |
| 暴击加成 | 暴击 / (暴击 + 等级 × 30) | 暴击伤害倍率1.5x-3.0x |
| 元素克制系数 | 1.3（克制）/ 0.7（被克制）/ 1.0（无关） | 元素克制关系 |
| 灵力加成 | 灵力 / (灵力 + 1000) | 灵力越高，技能伤害越高 |
| 阵法加成 | 根据洞府阵法等级 | 0%-50% |
| 仙盟加成 | 根据仙盟建筑等级 | 0%-30% |

### 特殊伤害机制

| 机制 | 说明 |
|------|------|
| 连击 | 攻击时有概率触发额外攻击 |
| 真实伤害 | 忽略防御的固定伤害 |
| 吸血 | 造成伤害的一定比例转化为生命恢复 |
| 反伤 | 受到攻击时反弹一定比例伤害 |
