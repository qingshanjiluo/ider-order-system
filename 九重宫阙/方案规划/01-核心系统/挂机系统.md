# 挂机系统

## 挂机模式

### 刷怪模式（主要模式）

| 项目 | 内容 |
|------|------|
| 产出 | 资源、灵石、装备、蛋、功法 |
| 限制 | 根据地图消耗体力 |
| 效率 | 根据地图等级和战力 |

### 不同地图

| 地图 | 难度 | 爆率 | 资源类型 |
|------|------|------|----------|
| 青云山麓 | 低 | 低 | 基础资源、灵石 |
| 幽冥谷 | 中低 | 中低 | 中级资源、灵石 |
| 火焰山 | 中 | 中 | 高级资源、灵石、装备 |
| 冰雪原 | 中高 | 中高 | 稀有资源、灵石、装备、蛋 |
| 雷霆深渊 | 高 | 高 | 珍稀资源、灵石、装备、蛋、功法 |

---

## 离线挂机

### 离线规则

| 规则 | 说明 |
|------|------|
| 离线收益 | 最多累计**250小时**收益 |
| 超时处理 | 超过上限需要上线领取 |
| 收益类型 | 根据挂机模式决定 |

---

## 体力恢复

### 恢复规则

| 规则 | 说明 |
|------|------|
| 恢复速度 | 每5分钟恢复1点体力 |
| 购买体力 | 可以花费灵石购买 |
| VIP无硬性加速 | VIP不直接加速体力恢复 |

---

## 挂机加速

### 加速规则

| 规则 | 说明 |
|------|------|
| VIP加速 | **VIP无硬性加速** |
| 套餐加速 | 可以购买套餐提高**灵气浓度和资质悟性**等 |
| 道具加速 | 使用道具加速挂机 |
| 加速上限 | 最高10倍速 |

### 可购买套餐效果

| 套餐效果 | 说明 |
|----------|------|
| 灵气浓度提升 | 提高挂机灵气获取效率 |
| 资质提升 | 提高修炼资质 |
| 悟性提升 | 提高功法领悟速度 |

---

## 智能挂机

### 智能规则

| 规则 | 说明 |
|------|------|
| 智能选择 | 根据玩家需求自动选择最优模式 |
| 资源优先 | 优先获取缺少的资源 |
| 效率优先 | 优先选择效率最高的地图 |

---

## 挂机收益

### 刷怪收益

| 收益类型 | 说明 |
|----------|------|
| 经验 | 战斗经验 |
| 灵石 | 灵石奖励（不同地图产出不同等级灵石） |
| 装备 | 随机装备 |
| 蛋 | 灵宠蛋（稀有掉落） |
| 功法 | 功法残页/碎片（稀有掉落） |
| 材料 | 随机材料 |

### 收益加成

| 加成类型 | 说明 |
|----------|------|
| 套餐加成 | 使用套餐获得灵气浓度/资质/悟性加成 |
| 洞府加成 | 洞府等级越高，加成越高 |
| 仙盟加成 | 仙盟建筑等级越高，加成越高 |
