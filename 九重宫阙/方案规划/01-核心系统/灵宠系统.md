|------|------|--------|
| 凡兽 | 上品→中品→下品→极品 | 常见 |
| 灵兽 | 上品→中品→下品→极品 | 少见 |
| 玄兽 | 上品→中品→下品→极品 | 稀有 |
| 地兽 | 上品→中品→下品→极品 | 极稀有 |

| 类型 | 说明 |

## 灵宠获取

### 获取方式

| 方式 | 说明 |
|------|------|
| **野外捕获** | 主要获取方式，击败野生灵宠后捕获 |
| 蛋孵化 | 通过蛋孵化获得（蛋可交易，灵宠不可交易） |

### 捕获规则

| 规则 | 说明 |
|------|------|
| 捕获条件 | 击败野生灵宠后可尝试捕获 |
| 捕获概率 | 根据灵宠品质和玩家等级决定 |
| 捕获消耗 | 消耗捕兽网/捕兽夹 |

### 蛋交易规则

| 规则 | 说明 |
|------|------|
| 蛋可交易 | 灵宠蛋可以在玩家间交易 |
| 灵宠不可交易 | 孵化后的灵宠绑定玩家，不可交易 |

---

## 灵宠契约

### 契约类型

| 契约类型 | 说明 |
|----------|------|
| **血契** | 绑定型契约，灵宠与玩家绑定，不可交易 |
| **平等契** | 非绑定型契约，灵宠可交易给其他玩家 |

### 契约规则

| 规则 | 说明 |
|------|------|
| 契约方式 | 捕获时选择契约类型 |
| 契约不可更改 | 一旦签订，不可更改契约类型 |
| 血契灵宠 | 战斗力+10%加成 |
| 平等契灵宠 | 无额外加成，但可交易 |

---

## 灵宠培养

### 培养方式

| 培养方式 | 说明 |
|----------|------|
| 喂丹药 | 提升灵宠属性和等级 |
| 喂肉类食物 | 提升灵宠饱食度和属性 |
| 洗髓液 | 重置灵宠属性，提升资质 |
| 灵草 | 缓慢提升灵宠属性 |

### 喂养规则

| 规则 | 说明 |
|------|------|
| 喂养材料 | 消耗灵宠食物/丹药/灵草 |
| 喂养上限 | 每日喂养次数有限 |
| 喂养效果 | 提升灵宠属性 |

### 升级规则

| 规则 | 说明 |
|------|------|
| 升级材料 | 消耗灵宠经验 |
| 升级上限 | 灵宠等级不能超过角色等级 |
| 升级成功率 | 100%成功 |

### 进化规则

| 规则 | 说明 |
|------|------|
| 进化材料 | 消耗进化石 |
| 进化条件 | 灵宠等级达到要求 |
| 进化效果 | 灵宠品质提升 |

---

## 灵宠技能

### 技能组成

| 技能类型 | 说明 |
|----------|------|
| 原版技能 | 灵宠自带技能，不可更改 |
| 灵宠功法 | 可增加**1个灵宠功法/技能** |

### 技能学习

| 规则 | 说明 |
|------|------|
| 学习条件 | 灵宠等级达到要求 |
| 学习材料 | 消耗技能书 |
| 技能上限 | 每只灵宠最多原版技能+1个功法技能 |

### 熟练度提升

| 方式 | 说明 |
|------|------|
| 出战提升 | 通过战斗提高技能熟练度 |
| 挂机修炼 | 灵宠可选择挂机修炼提升熟练度 |

## 灵宠战斗

### 战斗规则

| 规则 | 说明 |
|------|------|
| 出战数量 | 最多**2-3只**灵宠同时出战 |
| 战斗方式 | 自动战斗 |
| 战斗位置 | 跟随角色战斗 |

### 战斗加成

| 加成类型 | 说明 |
|----------|------|
| 属性加成 | 增加角色属性 |
| 技能加成 | 释放灵宠技能 |
| 特殊加成 | 特殊战斗效果 |
