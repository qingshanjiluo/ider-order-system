# 竞技系统

## 竞技场

### 竞技场规则

| 规则 | 说明 |
|------|------|
| 匹配机制 | **黑市匹配机制**（根据战力智能匹配） |
| 战斗方式 | 异步对战（AI控制对手） |
| 结算周期 | **每周结算**（非每日） |
| 排名奖励 | 每周结算，根据排名直接发放资源奖励 |

### 三榜分层

按照**注册时间**进行分层，分为三个榜单：

| 榜单 | 分层条件 | 说明 |
|------|----------|------|
| 天榜 | 注册时间≥6个月 | 老玩家榜单 |
| 地榜 | 注册时间3-6个月 | 中期玩家榜单 |
| 人榜 | 注册时间≤3个月 | 新玩家榜单 |

### 竞技场排名

| 排名 | 奖励 |
|------|------|
| 第1名 | 5000灵石+稀有装备+专属称号 |
| 第2名 | 4000灵石+稀有装备 |
| 第3名 | 3000灵石+稀有装备 |
| 第4-10名 | 2000灵石 |
| 第11-50名 | 1000灵石 |
| 第51-100名 | 500灵石 |
| 第101-500名 | 200灵石 |
| 第501-1000名 | 100灵石 |

### 赛季重置

| 规则 | 说明 |
|------|------|
| 重置周期 | 每周重置 |
| 重置内容 | 排名重置，奖励发放 |
| 重置目的 | 保持新鲜感 |

## 擂台赛

### 擂台赛规则

| 规则 | 说明 |
|------|------|
| 匹配机制 | 类似**黑市匹配机制** |
| 战斗方式 | 异步对战（AI控制对手） |
| 升级机制 | 胜利多少场升下一等级 |
| 奖励机制 | 胜利能获得奖励 |

### 挑战方式

| 方式 | 说明 |
|------|------|
| 发起挑战 | 可以主动挑战指定对手 |
| 匹配挑战 | 系统自动匹配对手 |

### 擂台赛等级

| 等级 | 升级条件 | 奖励 |
|------|----------|------|
| 铜级 | 初始 | 基础奖励 |
| 银级 | 胜利10场 | 银级奖励 |
| 金级 | 胜利30场 | 金级奖励 |
| 铂金级 | 胜利60场 | 铂金级奖励 |
| 钻石级 | 胜利100场 | 钻石级奖励 |

### 擂台赛奖励

| 等级 | 奖励 |
|------|------|
| 铜级 | 100灵石+基础材料 |
| 银级 | 300灵石+中级材料 |
| 金级 | 600灵石+高级材料+稀有装备 |
| 铂金级 | 1000灵石+稀有材料+传说装备 |
| 钻石级 | 2000灵石+珍稀材料+专属称号 |

## 仙盟战

### 仙盟战规则

| 规则 | 说明 |
|------|------|
| 参赛资格 | 仙盟等级6级以上 |
| 匹配机制 | 根据仙盟战力排名匹配 |
| 战斗形式 | 仙盟vs仙盟（10v10） |
| 比赛时间 | 每周六晚8点 |

### 仙盟战奖励

| 胜负 | 奖励 |
|------|------|
| 胜利 | 仙盟资源、领地、特殊buff |
| 失败 | 仙盟资源 |

### 仙盟战排名

| 排名 | 奖励 |
|------|------|
| 第1名 | 50000灵石+传说装备+专属称号 |
| 第2名 | 30000灵石+史诗装备+专属称号 |
| 第3名 | 20000灵石+稀有装备+专属称号 |
| 第4-10名 | 10000灵石+优秀装备 |
| 第11-50名 | 5000灵石 |
| 第51-100名 | 2000灵石 |
