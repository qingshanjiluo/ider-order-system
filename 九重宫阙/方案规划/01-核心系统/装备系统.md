# 装备系统

## 装备分类

### 装备类型

| 类型 | 说明 |
|------|------|
| 武器 | 增加攻击属性 |
| 防具 | 增加防御属性 |
| 饰品 | 增加多种属性 |

### 装备品质（九阶体系）

#### 常规九阶

| 阶位 | 名称 | 适用境界 |
|------|------|----------|
| 一阶 | 凡器 | 凡人~炼气 |
| 二阶 | 法器 | 炼气~筑基 |
| 三阶 | 灵器 | 筑基~金丹 |
| 四阶 | 法宝 | 金丹~元婴 |
| 五阶 | 古宝 | 元婴~化神 |
| 六阶 | 灵宝 | 化神~炼虚 |
| 七阶 | 道器 | 炼虚~合体 |
| 八阶 | 仙器 | 大乘~渡劫 |
| 九阶 | 混沌至宝 | 超脱 |

#### 每阶细分

**下品 → 中品 → 上品 → 极品**

| 品质 | 属性倍率 |
|------|----------|
| 下品 | ×1.0 |
| 中品 | ×1.3 |
| 上品 | ×1.6 |
| 极品 | ×2.0 |

## 装备强化

### 强化规则

| 规则 | 说明 |
|------|------|
| 强化次数 | 根据法宝等级决定上限 |
| 最低强化 | 3次 |
| 最高强化 | 25次 |
| 特殊神兵 | 可以**无限强化** |
| 强化材料 | 消耗强化石 |
| 强化成功率 | 根据强化次数递减 |

### 强化消耗

| 强化次数 | 强化石消耗 | 成功率 |
|----------|------------|--------|
| +1-+5 | 10个 | 100% |
| +6-+10 | 20个 | 80% |
| +11-+15 | 40个 | 60% |
| +16-+20 | 80个 | 40% |
| +21-+25 | 160个 | 20% |

### 强化效果

| 强化次数 | 属性加成 |
|----------|----------|
| +1-+5 | +5%属性/次 |
| +6-+10 | +10%属性/次 |
| +11-+15 | +15%属性/次 |
| +16-+20 | +20%属性/次 |
| +21-+25 | +25%属性/次 |

### 法痕规则
