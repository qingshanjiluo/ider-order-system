# 赛季系统

## 赛季规则

### 赛季时间

| 规则 | 说明 |
|------|------|
| 赛季周期 | **每月**（每月1日-月末） |
| 赛季结算 | 每月最后一天结算 |
| 赛季奖励 | 结算后发放 |
| 赛季重置 | 每月重置排名 |

### 赛季报名

| 规则 | 说明 |
|------|------|
| 报名费用 | **1000灵石**（每周报名一次即可） |
| 报名时间 | 每周可报名一次 |
| 参与资格 | 报名后即可参与赛季 |

### 赛季积分

| 获取方式 | 积分 |
|----------|------|
| 竞技场胜利 | +10积分 |
| 竞技场失败 | -5积分 |
| 仙盟战胜利 | +20积分 |
| 仙盟战失败 | -10积分 |
| 擂台赛胜利 | +15积分 |
| 擂台赛失败 | -8积分 |

## 赛季排名

### 排名规则

| 规则 | 说明 |
|------|------|
| 排名依据 | 赛季积分 |
| 排名时间 | 赛季结束后排名 |
| 排名奖励 | 根据排名发放奖励 |
| 全民奖励 | **所有人都有奖励**，只是多少区别 |

## 赛季任务

### 任务类型

| 任务类型 | 说明 |
|----------|------|
| 赛季每日任务 | 每日完成指定目标获取赛季积分 |
| 赛季每周任务 | 每周完成指定目标获取赛季积分 |
| 赛季成就任务 | 完成赛季特定成就获取额外奖励 |

### 任务示例

| 任务 | 目标 | 奖励 |
|------|------|------|
| 赛季首胜 | 赛季首次竞技场胜利 | 50积分 |
| 赛季百胜 | 赛季累计100次竞技场胜利 | 500积分+稀有材料 |
| 赛季探索 | 赛季累计探索100次 | 200积分 |
| 赛季副本 | 赛季累计通关50次副本 | 300积分 |
