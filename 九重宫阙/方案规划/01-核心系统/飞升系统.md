# 飞升系统

## 飞升规则

### 飞升条件

| 条件类型 | 具体要求 |
|----------|----------|
| 境界要求 | 等级合理（达到对应境界） |
| 渡劫战斗 | **参加渡劫战3次内成功**即可 |

### 飞升路径

| 路径 | 说明 |
|------|------|
| 飞升路径 | 1层 → 2层（线性，固定下一层） |
| 飞升转化 | 飞升玩家保留资源和资质，新玩家随机资质无资源 |
| 飞升奖励 | 2层新大陆、新技能、称号、重置优势 |

---

## 飞升转化

### 飞升玩家（老玩家）

| 保留内容 | 转化规则 |
|----------|----------|
| 资质 | 保留100%资质 |
| 资源 | 保留50%灵石、装备 |
| 功法 | 保留已学功法 |
| 灵宠 | 保留灵宠（等级减半） |
| 称号 | 保留飞升称号 |

### 新注册玩家

| 内容 | 规则 |
|------|------|
| 资质 | 随机抽取（可能比老玩家低） |
| 资源 | 无初始资源 |
| 功法 | 无 |
| 灵宠 | 无 |
| 称号 | 无 |

---

## 飞升奖励

### 奖励类型

| 奖励类型 | 内容 |
|----------|------|
| 新大陆 | 解锁2层地图 |
| 新技能 | 飞升专属技能 |
| 称号 | 飞升者称号（属性加成） |
| 重置优势 | 2层初始属性加成 |
| 特殊坐骑 | 飞升专属坐骑 |

### 奖励预览

| 奖励 | 预览 |
|------|------|
| 新大陆 | 2层全新地图 |
| 新技能 | 飞升专属技能×3 |
| 称号 | 飞升者称号（+10%全属性） |
| 重置优势 | 2层初始等级+10 |
| 特殊坐骑 | 飞升专属坐骑（+50%移动速度） |
