# 个人页面

## 页面布局

### 顶部区域
- 角色头像
- 角色昵称
- 等级显示
- 境界显示
- VIP等级

### 中部区域
- 战力面板（总战力、攻击、防御、生命、速度）
- 资质面板（灵根、悟性、属性点）
- 装备栏（当前装备显示）

### 底部区域
- 背包入口
- 成就入口
- 邀请入口

---

## 功能模块

### 角色信息

| 显示项 | 说明 |
|--------|------|
| 头像 | 玩家选择的头像 |
| 昵称 | 玩家自定义昵称 |
| 等级 | 当前等级 |
| 境界 | 当前境界（如：金丹中期） |
| VIP等级 | VIP等级显示 |

### 战力面板

| 属性 | 说明 |
|------|------|
| 总战力 | 综合战力评估 |
| 攻击 | 影响伤害输出 |
| 防御 | 影响受到伤害 |
| 生命 | 血量上限 |
| 速度 | 决定出手顺序 |

### 资质面板

| 属性 | 说明 |
|------|------|
| 灵根 | 影响修炼速度 |
| 悟性 | 影响功法学习速度 |
| 属性点 | 可分配的属性点 |

### 装备栏

| 位置 | 说明 |
|------|------|
| 武器 | 主要攻击装备 |
| 防具 | 防御装备 |
| 饰品 | 属性加成装备 |
| 坐骑 | 移动速度加成 |
| 灵宠 | 战斗伙伴 |

---

## UI交互

### 点击事件
- 点击头像：更换头像
- 点击昵称：修改昵称
- 点击装备：查看装备详情
- 点击属性：查看属性说明

### 长按事件
- 长按装备：装备强化/更换
- 长按属性：属性点分配

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/player/info | GET | 获取玩家信息 |
| /api/player/avatar | POST | 更换头像 |
| /api/player/nickname | POST | 修改昵称 |
| /api/player/attributes | POST | 分配属性点 |
