# 仙盟页面

## 页面布局

### 顶部区域
- 仙盟名称
- 仙盟等级
- 成员数量
- 公告栏

### 中部区域
- 成员列表
- 仙盟建筑
- 仙盟任务
- 仙盟商店

### 底部区域
- 仙盟探索
- 仙盟战
- 仙盟科技

---

## 功能模块

### 仙盟主页

| 功能 | 说明 |
|------|------|
| 仙盟信息 | 显示仙盟名称、等级、成员数 |
| 公告管理 | 盟主/副盟主发布公告 |
| 成员管理 | 管理成员、任命职位 |

### 成员列表

| 功能 | 说明 |
|------|------|
| 成员信息 | 显示成员昵称、等级、职位 |
| 在线状态 | 显示成员在线状态 |
| 成员操作 | 踢出成员、任命职位 |

### 仙盟建筑

| 功能 | 说明 |
|------|------|
| 建筑列表 | 显示仙盟建筑 |
| 建筑升级 | 升级仙盟建筑 |
| 建筑效果 | 显示建筑效果 |

### 仙盟任务

| 功能 | 说明 |
|------|------|
| 任务列表 | 显示仙盟任务 |
| 任务完成 | 完成任务获取贡献 |
| 任务奖励 | 领取任务奖励 |

### 仙盟商店

| 功能 | 说明 |
|------|------|
| 商品列表 | 显示可兑换商品 |
| 贡献兑换 | 使用贡献兑换商品 |
| 商品详情 | 查看商品详情 |

### 仙盟探索

| 功能 | 说明 |
|------|------|
| 探索地图 | 显示仙盟探索地图 |
| 组队探索 | 组队探索获取奖励 |
| 探索奖励 | 领取探索奖励 |

### 仙盟战

| 功能 | 说明 |
|------|------|
| 对阵图 | 显示仙盟战对阵图 |
| 战斗记录 | 查看战斗记录 |
| 赛季排名 | 查看赛季排名 |

---

## UI交互

### 点击事件
- 点击仙盟主页：进入仙盟主页
- 点击成员列表：查看成员列表
- 点击仙盟建筑：进入建筑界面
- 点击仙盟任务：进入任务界面
- 点击仙盟商店：进入商店界面
- 点击仙盟探索：进入探索界面
- 点击仙盟战：进入战斗界面

### 滑动事件
- 左右滑动：切换仙盟功能
- 上下滑动：查看成员列表

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/alliance/info | GET | 获取仙盟信息 |
| /api/alliance/announcement | POST | 发布公告 |
| /api/alliance/members | GET | 获取成员列表 |
| /api/alliance/members/kick | POST | 踢出成员 |
| /api/alliance/members/appoint | POST | 任命职位 |
| /api/alliance/buildings | GET | 获取建筑列表 |
| /api/alliance/buildings/upgrade | POST | 升级建筑 |
| /api/alliance/tasks | GET | 获取任务列表 |
| /api/alliance/tasks/complete | POST | 完成任务 |
| /api/alliance/shop | GET | 获取商店列表 |
| /api/alliance/shop/purchase | POST | 购买商品 |
| /api/alliance/exploration | GET | 获取探索地图 |
| /api/alliance/exploration/start | POST | 开始探索 |
| /api/alliance/war | GET | 获取仙盟战信息 |
| /api/alliance/war/join | POST | 加入仙盟战 |
