# 修炼页面

## 页面布局

### 顶部区域
- 当前境界显示
- 经验条
- 突破按钮

### 中部区域
- 挂机选择（修行/刷怪）
- 挂机收益预览
- 离线收益显示

### 底部区域
- 功法列表
- 洞府管理入口

---

## 功能模块

### 修炼面板

| 显示项 | 说明 |
|--------|------|
| 当前境界 | 如：金丹中期 |
| 经验条 | 显示当前经验和升级所需经验 |
| 突破按钮 | 点击进行突破尝试 |

### 突破模拟器

| 显示项 | 说明 |
|--------|------|
| 当前成功率 | 显示突破成功率 |
| 失败惩罚预览 | 显示失败后的惩罚 |
| 突破材料 | 显示所需材料 |

### 挂机系统

| 功能 | 说明 |
|------|------|
| 修行模式 | 选择修行获取经验 |
| 刷怪模式 | 选择刷怪获取装备/材料 |
| 收益预览 | 显示每小时收益 |
| 离线收益 | 上线后显示离线收益 |

### 功法系统

| 功能 | 说明 |
|------|------|
| 已学功法 | 显示已学习的功法 |
| 功法升级 | 升级功法消耗材料 |
| 功法装备 | 装备功法到技能栏 |

### 洞府管理

| 功能 | 说明 |
|------|------|
| 洞府等级 | 显示洞府等级 |
| 灵气浓度 | 显示灵气浓度 |
| 洞府升级 | 升级洞府消耗资源 |

---

## UI交互

### 点击事件
- 点击突破按钮：进行突破尝试
- 点击挂机选择：切换挂机模式
- 点击功法：查看功法详情
- 点击洞府管理：进入洞府界面

### 滑动事件
- 左右滑动：切换挂机模式
- 上下滑动：查看功法列表

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/cultivation/info | GET | 获取修炼信息 |
| /api/cultivation/breakthrough | POST | 进行突破 |
| /api/cultivation/afk | POST | 开始挂机 |
| /api/cultivation/offline-reward | GET | 获取离线收益 |
| /api/cultivation/techniques | GET | 获取功法列表 |
| /api/cultivation/cave | GET | 获取洞府信息 |
