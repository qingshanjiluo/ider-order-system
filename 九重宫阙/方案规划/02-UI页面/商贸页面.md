# 商贸页面

## 页面布局

### 顶部区域
- 货币显示（点券、灵石）
- 商城入口

### 中部区域
- 拍卖行
- 灵石商店
- 点券商店
- 荣誉商店
- 仙盟商店
- 神秘商人

### 底部区域
- 交易记录
- 收藏夹

---

## 功能模块

### 商城系统

| 功能 | 说明 |
|------|------|
| 套餐购买 | 购买各种套餐 |
| VIP购买 | 购买VIP等级 |
| 限时折扣 | 限时折扣商品 |

### 拍卖行系统

| 功能 | 说明 |
|------|------|
| 物品上架 | 出售物品 |
| 物品搜索 | 搜索物品 |
| 物品购买 | 购买物品 |
| 交易记录 | 查看交易记录 |

### 灵石商店

| 功能 | 说明 |
|------|------|
| 灵石购买 | 使用灵石购买物品 |
| 物品兑换 | 兑换物品 |

### 点券商店

| 功能 | 说明 |
|------|------|
| 点券购买 | 使用点券购买物品 |
| 物品兑换 | 兑换物品 |

### 荣誉商店

| 功能 | 说明 |
|------|------|
| 荣誉兑换 | 使用荣誉兑换物品 |
| 物品列表 | 显示可兑换物品 |

### 仙盟商店

| 功能 | 说明 |
|------|------|
| 贡献兑换 | 使用贡献兑换物品 |
| 物品列表 | 显示可兑换物品 |

### 神秘商人

| 功能 | 说明 |
|------|------|
| 随机商品 | 随机刷新商品 |
| 限时购买 | 限时购买机会 |

---

## UI交互

### 点击事件
- 点击商城：进入商城界面
- 点击拍卖行：进入拍卖行界面
- 点击灵石商店：进入灵石商店界面
- 点击点券商店：进入点券商店界面
- 点击荣誉商店：进入荣誉商店界面
- 点击仙盟商店：进入仙盟商店界面
- 点击神秘商人：进入神秘商人界面

### 滑动事件
- 左右滑动：切换商店分类
- 上下滑动：查看商品列表

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/shop/currency | GET | 获取货币信息 |
| /api/shop/mall/packages | GET | 获取套餐列表 |
| /api/shop/mall/purchase | POST | 购买套餐 |
| /api/shop/mall/vip | GET | 获取VIP信息 |
| /api/shop/mall/vip/purchase | POST | 购买VIP |
| /api/shop/auction/list | GET | 获取拍卖行列表 |
| /api/shop/auction/listing | POST | 上架物品 |
| /api/shop/auction/purchase | POST | 购买物品 |
| /api/shop/spirit-stone/list | GET | 获取灵石商店列表 |
| /api/shop/spirit-stone/purchase | POST | 购买物品 |
| /api/shop/points/list | GET | 获取点券商店列表 |
| /api/shop/points/purchase | POST | 购买物品 |
| /api/shop/honor/list | GET | 获取荣誉商店列表 |
| /api/shop/honor/purchase | POST | 购买物品 |
| /api/shop/alliance/list | GET | 获取仙盟商店列表 |
| /api/shop/alliance/purchase | POST | 购买物品 |
| /api/shop/mysterious/refresh | POST | 刷新神秘商人 |
| /api/shop/mysterious/purchase | POST | 购买物品 |
