# 宗门页面

## 页面布局

### 顶部区域
- 宗门名称
- 宗门等级
- 成员数量
- 公告栏

### 中部区域
- 宗门任务
- 宗门地图
- 宗门商店
- 宗门战

### 底部区域
- 宗门建筑
- 宗门科技

---

## 功能模块

### 宗门主页

| 功能 | 说明 |
|------|------|
| 宗门信息 | 显示宗门名称、等级、成员数 |
| 公告管理 | 宗主/副宗主发布公告 |
| 成员管理 | 管理成员、任命职位 |

### 宗门任务

| 功能 | 说明 |
|------|------|
| 任务列表 | 显示宗门任务 |
| 任务完成 | 完成任务获取贡献 |
| 任务奖励 | 领取任务奖励 |

### 宗门地图

| 功能 | 说明 |
|------|------|
| 地图入口 | 进入宗门专属地图 |
| 地图详情 | 查看地图详情 |
| 地图奖励 | 查看地图奖励 |

### 宗门商店

| 功能 | 说明 |
|------|------|
| 商品列表 | 显示可兑换商品 |
| 贡献兑换 | 使用贡献兑换商品 |
| 商品详情 | 查看商品详情 |

### 宗门战

| 功能 | 说明 |
|------|------|
| 对阵图 | 显示宗门战对阵图 |
| 战斗记录 | 查看战斗记录 |
| 赛季排名 | 查看赛季排名 |

### 宗门建筑

| 功能 | 说明 |
|------|------|
| 建筑列表 | 显示宗门建筑 |
| 建筑升级 | 升级宗门建筑 |
| 建筑效果 | 显示建筑效果 |

### 宗门科技

| 功能 | 说明 |
|------|------|
| 科技列表 | 显示宗门科技 |
| 科技升级 | 升级宗门科技 |
| 科技效果 | 显示科技效果 |

---

## UI交互

### 点击事件
- 点击宗门主页：进入宗门主页
- 点击宗门任务：进入任务界面
- 点击宗门地图：进入地图界面
- 点击宗门商店：进入商店界面
- 点击宗门战：进入战斗界面
- 点击宗门建筑：进入建筑界面
- 点击宗门科技：进入科技界面

### 滑动事件
- 左右滑动：切换宗门功能
- 上下滑动：查看任务列表

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/sect/info | GET | 获取宗门信息 |
| /api/sect/announcement | POST | 发布公告 |
| /api/sect/tasks | GET | 获取任务列表 |
| /api/sect/tasks/complete | POST | 完成任务 |
| /api/sect/maps | GET | 获取地图列表 |
| /api/sect/maps/enter | POST | 进入地图 |
| /api/sect/shop | GET | 获取商店列表 |
| /api/sect/shop/purchase | POST | 购买商品 |
| /api/sect/war | GET | 获取宗门战信息 |
| /api/sect/war/join | POST | 加入宗门战 |
| /api/sect/buildings | GET | 获取建筑列表 |
| /api/sect/buildings/upgrade | POST | 升级建筑 |
| /api/sect/technologies | GET | 获取科技列表 |
| /api/sect/technologies/upgrade | POST | 升级科技 |
