# 洞府页面

## 页面布局

### 顶部区域
- 洞府名称
- 洞府等级
- 灵气浓度

### 中部区域
- 灵田区域（种植灵植）
- 灵宠窝（灵宠展示）
- 储物箱（洞府存储）

### 底部区域
- 聚灵阵
- 装备强化
- 炼丹炉

---

## 功能模块

### 灵田系统

| 功能 | 说明 |
|------|------|
| 灵田数量 | 根据洞府等级解锁灵田 |
| 灵植种植 | 种植灵植获取资源 |
| 收获时间 | 灵植成熟时间 |
| 灵植品质 | 白→绿→蓝→紫→橙→红 |

### 灵宠系统

| 功能 | 说明 |
|------|------|
| 灵宠展示 | 显示当前灵宠 |
| 灵宠喂养 | 喂养灵宠提升属性 |
| 灵宠升级 | 升级灵宠解锁技能 |
| 灵宠商店 | 购买灵宠蛋 |

### 储物箱系统

| 功能 | 说明 |
|------|------|
| 物品存储 | 存储游戏物品 |
| 物品取出 | 取出物品到背包 |
| 物品整理 | 自动整理物品 |

### 聚灵阵系统

| 功能 | 说明 |
|------|------|
| 聚灵阵等级 | 显示聚灵阵等级 |
| 灵气加成 | 显示灵气加成效果 |
| 聚灵阵升级 | 升级聚灵阵消耗资源 |

### 装备强化系统

| 功能 | 说明 |
|------|------|
| 装备选择 | 选择要强化的装备 |
| 强化材料 | 显示所需材料 |
| 强化成功率 | 显示强化成功率 |
| 强化预览 | 预览强化后属性 |

### 炼丹系统

| 功能 | 说明 |
|------|------|
| 丹药配方 | 显示可炼制的丹药 |
| 炼制材料 | 显示所需材料 |
| 炼制成功率 | 显示炼制成功率 |
| 炼制结果 | 显示炼制结果 |

---

## UI交互

### 点击事件
- 点击灵田：种植/收获灵植
- 点击灵宠：查看灵宠详情
- 点击储物箱：查看/取出物品
- 点击聚灵阵：查看/升级聚灵阵
- 点击装备强化：进入强化界面
- 点击炼丹炉：进入炼丹界面

### 长按事件
- 长按灵植：查看灵植详情
- 长按灵宠：查看灵宠详情
- 长按物品：查看物品详情

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/cave/info | GET | 获取洞府信息 |
| /api/cave/field/plant | POST | 种植灵植 |
| /api/cave/field/harvest | POST | 收获灵植 |
| /api/cave/pet/list | GET | 获取灵宠列表 |
| /api/cave/pet/feed | POST | 喂养灵宠 |
| /api/cave/storage/list | GET | 获取储物箱物品 |
| /api/cave/storage/withdraw | POST | 取出物品 |
| /api/cave/spirit-array/upgrade | POST | 升级聚灵阵 |
| /api/cave/equipment/enhance | POST | 强化装备 |
| /api/cave/alchemy/craft | POST | 炼制丹药 |
