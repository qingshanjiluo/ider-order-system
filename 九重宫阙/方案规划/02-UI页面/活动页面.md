# 活动页面

## 页面布局

- 活动分类标签
- 当前活动提示

### 中部区域
- 每日签到
- 限时活动
- 赛季活动

- 任务系统

## UI交互

### 点击事件
- 点击每日签到：领取签到奖励
- 点击限时活动：进入活动详情
- 点击赛季活动：进入赛季详情
- 点击成就系统：进入成就界面
- 点击任务系统：进入任务界面
- 点击邀请活动：进入邀请界面

### 滑动事件
- 左右滑动：切换活动分类
- 上下滑动：查看活动列表

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/activity/sign-in | GET | 获取签到信息 |
| /api/activity/sign-in/claim | POST | 领取签到奖励 |
| /api/activity/limited-time | GET | 获取限时活动 |
| /api/activity/limited-time/claim | POST | 领取活动奖励 |
| /api/activity/season | GET | 获取赛季活动 |
| /api/activity/season/claim | POST | 领取赛季奖励 |
| /api/activity/achievements | GET | 获取成就列表 |
| /api/activity/achievements/claim | POST | 领取成就奖励 |
| /api/activity/tasks/daily | GET | 获取每日任务 |
| /api/activity/tasks/main | GET | 获取主线任务 |
| /api/activity/tasks/claim | POST | 领取任务奖励 |
| /api/activity/invite | GET | 获取邀请信息 |
| /api/activity/invite/claim | POST | 领取邀请奖励 |
