# 百艺页面

## 页面布局

### 顶部区域
- 百艺技能分类标签
- 技能等级显示

### 中部区域
- 炼丹
- 炼器
- 阵法
- 符箓
- 灵植
- 采集

### 底部区域
- 技能树
- 技能升级

---

## 功能模块

### 炼丹系统

| 功能 | 说明 |
|------|------|
| 丹药配方 | 显示可炼制的丹药 |
| 炼制材料 | 显示所需材料 |
| 炼制成功率 | 显示炼制成功率 |

## UI交互

### 点击事件
- 点击炼丹：进入炼丹界面
- 点击炼器：进入炼器界面
- 点击阵法：进入阵法界面
- 点击符箓：进入符箓界面
- 点击灵植：进入灵植界面
- 点击采集：进入采集界面

### 滑动事件
- 左右滑动：切换百艺技能
- 上下滑动：查看技能详情

### API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/arts/alchemy/recipes | GET | 获取炼丹配方 |
| /api/arts/alchemy/craft | POST | 炼制丹药 |
| /api/arts/forging/recipes | GET | 获取炼器配方 |
| /api/arts/forging/craft | POST | 打造装备 |
| /api/arts/formation/skills | GET | 获取阵法技能 |
| /api/arts/formation/learn | POST | 学习阵法 |
| /api/arts/talisman/skills | GET | 获取符箓技能 |
| /api/arts/talisman/learn | POST | 学习符箓 |
| /api/arts/herbology/plants | GET | 获取灵植列表 |
| /api/arts/herbology/plant | POST | 种植灵植 |
| /api/arts/gathering/resources | GET | 获取采集资源 |
| /api/arts/gathering/gather | POST | 采集资源 |
