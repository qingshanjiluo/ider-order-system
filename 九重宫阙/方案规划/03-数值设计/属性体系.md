# 属性体系

## 基础属性

| 属性 | 说明 | 计算公式 |
|------|------|----------|
| 攻击 | 影响伤害输出 | 基础攻击 + 装备攻击 + 功法攻击 |
| 防御 | 影响受到伤害 | 基础防御 + 装备防御 + 功法防御 |
| 生命 | 血量上限 | 基础生命 + 装备生命 + 功法生命 |
| 速度 | 决定出手顺序 | 基础速度 + 装备速度 + 功法速度 |
| 暴击 | 暴击概率 | 基础暴击 + 装备暴击 + 功法暴击 |
| 闪避 | 闪避概率 | 基础闪避 + 装备闪避 + 功法闪避 |

## 战力计算

### 战力公式

```
总战力 = 基础属性 + 装备属性 + 功法属性 + 灵宠属性 + 仙盟buff
```

### 属性权重

| 属性 | 权重 |
|------|------|
| 攻击 | 1.0 |
| 防御 | 0.8 |
| 生命 | 0.5 |
| 速度 | 0.3 |
| 暴击 | 0.2 |
| 闪避 | 0.2 |

### 战力计算示例

```
基础属性 = 攻击×1.0 + 防御×0.8 + 生命×0.5 + 速度×0.3 + 暴击×0.2 + 闪避×0.2
装备属性 = 装备攻击×1.0 + 装备防御×0.8 + 装备生命×0.5 + 装备速度×0.3
功法属性 = 功法攻击×1.0 + 功法防御×0.8 + 功法生命×0.5 + 功法速度×0.3
灵宠属性 = 灵宠攻击×1.0 + 灵宠防御×0.8 + 灵宠生命×0.5 + 灵宠速度×0.3
仙盟buff = 仙盟攻击×1.0 + 仙盟防御×0.8 + 仙盟生命×0.5 + 仙盟速度×0.3

总战力 = 基础属性 + 装备属性 + 功法属性 + 灵宠属性 + 仙盟buff
```
