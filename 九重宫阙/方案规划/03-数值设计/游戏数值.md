## 战斗数值

### 属性权重

| 属性 | 权重 | 说明 |
|------|------|------|
| 攻击 | 1.0 | 主要输出属性 |
| 防御 | 0.8 | 主要防御属性 |
| 生命 | 0.5 | 生存属性 |
| 速度 | 0.3 | 先手属性 |
| 暴击 | 0.2 | 爆发属性 |
| 闪避 | 0.2 | 生存属性 |

### 伤害公式

```
伤害 = 攻击 × (1 + 暴击加成) × (1 - 防御减伤)
防御减伤 = 防御 / (防御 + 1000)
暴击加成 = 暴击 / (暴击 + 1000)
```

### 战力公式

```
总战力 = 基础属性 + 装备属性 + 功法属性 + 灵宠属性 + 仙盟buff
```
