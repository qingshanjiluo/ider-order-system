## 宗门地图规则

### 进入条件

| 条件 | 说明 |
|------|------|
| 宗门归属 | 必须加入对应宗门 |
| 境界要求 | 根据地图等级有境界要求 |
| 进入次数 | 每日有次数限制 |

### 掉落规则

| 规则 | 说明 |
|------|------|
| 专属掉落 | 只掉落本宗门特色物品 |
| 掉落加成 | 宗门成员有掉落加成 |
| 组队加成 | 组队进入有额外掉落 |

### 特殊事件

| 事件 | 说明 |
|------|------|
| 宗门BOSS | 随机刷新宗门BOSS |
| 宗门任务 | 触发宗门专属任务 |
| 宗门宝藏 | 发现宗门隐藏宝藏 |
