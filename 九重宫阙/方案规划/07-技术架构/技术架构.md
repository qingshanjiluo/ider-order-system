# 技术架构

## 技术栈

### 前端技术

| 技术 | 说明 |
|------|------|
| 框架 | Vue.js / React |
| UI库 | 自定义古风UI组件库 |
| 游戏引擎 | Phaser.js / Pixi.js |
| 状态管理 | Vuex / Redux |
| 网络请求 | Axios |

### 后端技术

| 技术 | 说明 |
|------|------|
| 语言 | Node.js |
| 框架 | Express / Koa |
| 数据库 | MySQL / MongoDB |
| 缓存 | Redis |
| 消息队列 | RabbitMQ / Kafka |

### 部署技术

| 技术 | 说明 |
|------|------|
| 服务器 | 云服务器（阿里云/腾讯云） |
| 容器化 | Docker |
| 负载均衡 | Nginx |
| CDN | 云CDN |

## 系统架构

### 前端架构

```
├── 视图层（View）
│   ├── 页面组件
│   ├── UI组件
│   └── 游戏画面
├── 逻辑层（Logic）
│   ├── 游戏逻辑
│   ├── UI逻辑
│   └── 网络逻辑
└── 数据层（Data）
    ├── 本地存储
    ├── 状态管理
    └── 网络数据
```

### 后端架构

```
├── 接口层（API）
│   ├── RESTful API
│   ├── WebSocket
│   └── GraphQL
├── 业务层（Business）
│   ├── 用户系统
│   ├── 游戏系统
│   └── 支付系统
└── 数据层（Data）
    ├── 数据库
    ├── 缓存
    └── 文件存储
```

## 数据库设计

### 用户表（users）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 用户ID |
| username | VARCHAR | 用户名 |
| password | VARCHAR | 密码 |
| nickname | VARCHAR | 昵称 |
| avatar | VARCHAR | 头像 |
| vip_level | INT | VIP等级 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 角色表（characters）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 角色ID |
| user_id | INT | 用户ID |
| name | VARCHAR | 角色名 |
| level | INT | 等级 |
| realm | VARCHAR | 境界 |
| realm_stage | VARCHAR | 境界阶段 |
| experience | BIGINT | 经验 |
| combat_power | BIGINT | 战力 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 装备表（equipment）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 装备ID |
| character_id | INT | 角色ID |
| type | VARCHAR | 装备类型 |
| name | VARCHAR | 装备名称 |
| level | INT | 装备等级 |
| quality | VARCHAR | 装备品质 |
| attributes | JSON | 装备属性 |
| created_at | DATETIME | 创建时间 |

### 物品表（items）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 物品ID |
| character_id | INT | 角色ID |
| name | VARCHAR | 物品名称 |
| quantity | INT | 数量 |
| type | VARCHAR | 物品类型 |
| created_at | DATETIME | 创建时间 |
