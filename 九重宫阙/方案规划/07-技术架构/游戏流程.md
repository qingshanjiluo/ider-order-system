# 游戏流程

## 新手引导

### 引导步骤

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 创建角色 | 选择性别、输入昵称 |
| 2 | 选择宗门 | 选择加入的宗门 |
| 3 | 基础操作 | 学习移动、攻击、使用物品 |
| 4 | 第一次战斗 | 完成新手副本 |
| 5 | 领取奖励 | 领取新手奖励 |

### 引导奖励

| 奖励 | 数量 |
|------|------|
| 经验 | 1000 |
| 灵石 | 1000 |
| 装备 | 新手套装 |
| 功法 | 基础功法 |
