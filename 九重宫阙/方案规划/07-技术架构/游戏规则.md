# 游戏规则

## 基础规则

### 角色规则

| 规则 | 说明 |
|------|------|
| 角色创建 | 每个账号只能创建1个角色 |
| 角色命名 | 2-12个字符，不能重复 |
| 角色删除 | 删除后7天内可恢复 |

### 等级规则

| 规则 | 说明 |
|------|------|
| 等级上限 | 当前版本等级上限为100级 |
| 经验获取 | 通过挂机、副本、任务获取经验 |
| 突破条件 | 满足经验后可尝试突破 |

### 境界规则

| 规则 | 说明 |
|------|------|
| 境界体系 | 炼气→筑基→金丹→元婴→化神→渡劫→大乘→飞升 |
| 境界阶段 | 每个境界分前期/中期/后期/半步（高阶） |
| 突破概率 | 根据资质、洞府、道具等因素计算 |

## 战斗规则

### PVE规则

| 规则 | 说明 |
|------|------|
| 战斗方式 | 自动战斗 |
| 战斗时间 | 最多3分钟 |
| 胜利条件 | 击败所有敌人 |
| 失败条件 | 全部阵亡 |

### PVP规则

| 规则 | 说明 |
|------|------|
| 战斗方式 | 自动战斗/实时操作 |
| 战斗时间 | 最多5分钟 |
| 胜利条件 | 击败对手 |
| 失败条件 | 全部阵亡 |

### 仙盟战规则

| 规则 | 说明 |
|------|------|
| 参赛资格 | 仙盟等级6级以上 |
| 战斗形式 | 10v10 |
| 战斗时间 | 每周六晚8点 |
| 胜利条件 | 击败对手仙盟 |

## 经济规则

### 灵石规则

| 规则 | 说明 |
|------|------|
| 获取方式 | 挂机、副本、任务、充值 |
| 消耗方式 | 升级、强化、购买 |
| 交易方式 | 拍卖行交易 |

### 点券规则

| 规则 | 说明 |
|------|------|
| 获取方式 | 充值、邀请返现 |
| 消耗方式 | 购买套餐、VIP |
| 交易方式 | 不能交易 |

### VIP规则

| 规则 | 说明 |
|------|------|
| 获取方式 | 点券或灵石购买 |
| 特权 | 头衔、奖励加成、充值优惠 |
| 续费 | 到期前7天可续费 |

## 社交规则

### 仙盟规则

| 规则 | 说明 |
|------|------|
| 加入条件 | 等级达到10级 |
| 人数上限 | 根据仙盟等级 |
| 职位权限 | 盟主/副盟主/长老/精英/成员 |
| 退出惩罚 | 退出后24小时不能加入新仙盟 |

### 好友规则

| 规则 | 说明 |
|------|------|
| 添加条件 | 等级达到5级 |
| 好友上限 | 50人 |
| 好友互动 | 聊天、组队、赠送 |

### 聊天规则

| 规则 | 说明 |
|------|------|
| 聊天频道 | 世界、仙盟、私聊 |
| 禁言规则 | 违规言论会被禁言 |
| 举报规则 | 可以举报违规玩家 |

## 活动规则

| 规则 | 说明 |

|------|------|
| 每日任务 | 每日0:00刷新 |
| 主线任务 | 完成后解锁下一个 |
| 任务奖励 | 完成任务后领取 |

### 赛季规则

| 规则 | 说明 |
|------|------|
| 赛季时间 | 每月1日-月末 |

| 赛季奖励 | 赛季结束后发放 |
