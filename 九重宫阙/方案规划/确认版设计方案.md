# 九重宫阙 - 确认版设计方案

> 基于问卷确认，2026年8月31日整理

---

## 一、修炼系统

### 境界划分（确认）
| 境界 | 等级范围 | 阶段 |
|------|----------|------|
| 炼气 | 1-10 | 前期→中期→后期 |
| 筑基 | 11-20 | 前期→中期→后期 |
| 金丹 | 21-30 | 前期→中期→后期 |
| 元婴 | 31-40 | 前期→中期→后期→半步 |
| 化神 | 41-50 | 前期→中期→后期→半步 |
| 渡劫 | 51-60 | 前期→中期→后期→半步 |
| 大乘 | 61-70 | 前期→中期→后期→半步 |
| 飞升 | 71+ | 前期→中期→后期→半步 |

### 突破失败惩罚（用户自定义）
| 失败次数 | 惩罚内容 |
|----------|----------|
| 1-3次 | 清除当前经验积累 |
| 4-5次 | 增加下次突破难度 |
| 6-7次 | 降低资质1点 |
| 8次+ | 增加渡劫难度 + 突破难度 + 资质下降（累计总次数，不只是当前境界） |

### 渡劫战斗触发（确认）
- **化神以上境界**突破时触发渡劫战斗

### 洞府系统（用户自定义）
洞府是**修炼辅助物品放置位置**，可放置：
- 阵法（提升修炼效率）
- 灵植（产出灵草）
- 法器（属性加成）
- 俘虏（特殊效果）
- 其他辅助道具

### 修炼速度（确认）
- 保持原设计，境界越高升级所需经验越多

## 二、战斗系统

### 战斗方式（用户自定义）
- **自动为主**
- 支持**手动调整功法顺序优先级**

### 伤害公式（用户反馈：太简单）
需要重新设计更复杂的伤害公式，增加更多属性影响

### 战斗时间限制（用户自定义）
- **不限制时间**

### 技能系统（用户自定义）
- **整个技能体系完全重做**
- 根据**各个宗门流派**制作不同技能

### 属性克制（用户自定义）
- 与修行相关
- 灵石有属性（特殊灵石）
- 使用特殊灵石可以提高**特殊灵根修炼速度**

## 四、装备系统

### 装备品质（用户自定义）

#### 常规九阶
| 阶位 | 名称 | 适用境界 |
|------|------|----------|
| 一阶 | 凡器 | 凡人~炼气 |
| 二阶 | 法器 | 炼气~筑基 |
| 三阶 | 灵器 | 筑基~金丹 |
| 四阶 | 法宝 | 金丹~元婴 |
| 五阶 | 古宝 | 元婴~化神 |
| 六阶 | 灵宝 | 化神~炼虚 |
| 七阶 | 道器 | 炼虚~合体 |
| 八阶 | 仙器 | 大乘~渡劫 |
| 九阶 | 混沌至宝 | 超脱 |

#### 每阶细分
**下品 → 中品 → 上品 → 极品**

### 装备强化（用户自定义）
- 根据**法宝等级**决定强化上限
- 最低等强化3次
- 最高强化25次
- 特殊神兵可以**无限强化**

### 套装效果（用户自定义）
- 进行平衡性调整
- 整体范围：**10%-90%**

### 装备升星（用户自定义）
改为**元素法痕**系统：
- 根据炼制等级有不同属性、数量的痕迹
- 最高**5纹**

### 装备获取（确认）
- **炼器为主**

## 总结

### 保留原设计的系统
- 修炼系统（境界划分、修炼速度）
- 副本系统（BOSS设计）
- 签到系统（全部）
- 成就系统（全部）
- 飞升系统（转化、奖励、新玩家补偿）

### 需要大幅修改的系统
- 战斗系统（技能体系重做、伤害公式重做、无时间限制）
- 装备系统（九阶品质、强化上限、元素法痕）
- 功法系统（修炼/战斗分类、品质体系）
- 灵宠系统（品质体系、培养方式、契约方式）

### 需要调整的系统
- 副本系统（类型重新划分、5星评价）
- 仙盟系统（职位自定义、仙盟战改为组队战）
- 变现系统（VIP10级、套餐扩展、小额充值）
- 竞技系统（三榜分层、擂台赛机制）
- 赛季系统（全民奖励、报名费）
- 挂机系统（离线250小时、VIP加速改为套餐）
