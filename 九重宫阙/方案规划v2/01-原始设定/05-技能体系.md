# 技能体系

> 来源：杂项（图7）技能部分

## 一、技能配置规则

| 规则 | 内容 |
|---|---|
| 主技 | **1 个** |
| 基础总配置 | **3 个技能** |
| 上限提升 | 通过提升**等级**、**资质**和**修炼相关功法**提高上限 |
| 可学习数量 | 可以学习**多个**（不止装备的） |
| 最终战斗配置 | **最多 10 个**技能 |
| CD 惩罚 | 技能数超过 5 个后，**数量越多 CD 越翻倍** |

## 二、特殊技能来源

| 来源 | 说明 |
|---|---|
| 特殊装备技能 | 法器/装备携带的技能 |
| 特殊灵根被动 | 特殊灵根自带的被动技能 |
| 灵宠技能 | 灵宠提供 |
| key 技能 | **多轮后必释放**的技能（保底释放机制） |

## 三、设计要点提炼

1. 技能栏是**动态解锁**的：3 基础 → 等级/资质/功法解锁 → 上限 10
2. 10 格满配有 **CD 翻倍代价** → 格子数量与爆发频率的权衡（防堆叠无敌）
3. key 技能 = 多轮后强制释放 → 防"永远攒不出关键技能"的循环死锁
