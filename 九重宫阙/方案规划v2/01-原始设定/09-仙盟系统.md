# 仙盟系统

> 来源：杂项（图1）表2 + 杂项（图3）仙盟行

## 一、创建

| 项 | 说明 |
|---|---|
| 创建需要 | **仙盟令** |
| 仙盟令获取来源 | **礼包、拍卖、邀请奖励** |
| 创建方式 | 创建、搜索、申请、推荐 |

## 二、仙盟内容

| 模块 | 说明 |
|---|---|
| 成员 | 可以**赠送灵石** |
| 建筑 | **建设队列**，和其他队列**串行**；**参与建设就无法修炼和刷怪**；**参与人数越多越快** |
| 聊天 | 仙盟内聊天 |
| 任务 | — |
| 管理 | 批准、建设、成员管理 |
| 盟内活动 | 盟战等 |

## 三、设计要点提炼

1. **仙盟令**是稀缺凭证（礼包/拍卖/邀请奖励三渠道）——创建门槛由"货币"改为"道具"
2. **建设队列串行 + 机会成本**：参与建设 = 放弃修炼和刷怪 → 建设是真实的时间投资
3. **人数加速**：多人参与建设缩短队列时间 → 激励协作
