# AI 系统

> 来源：ai系统（图9）

## 一、AI 应用（基础设施）

- **管理后台可控**：可填入**多个密钥、URL 和模型**
- 可设置**不同功能对应的模型**
- **容灾**：当测速密钥失败时，全部相关功能替换备用或可用密钥；如果皆不可用，相关功能**失效并点击显示报错**

## 二、AI 内容生成点（6 类）

### 1. 炼器 · 器方
- 根据不同等级、特殊技能，提高以前没有的炼制配方成功率
- **词条**：在无匹配配方时**有概率炼制出全新（名字）**；成功后会获得一个**全新配方**和一个**对应物**

### 2. 炼丹
- 类似炼器

### 3. 仙盟
- 仙盟任务 / 仙盟建筑 / 头衔 / 仙盟介绍

### 4. 剧情
- 副本经历 / 传承 / 渡劫
- （联动 Sheet1：AI 预制开局文案、特殊体质单独生成、按记年事件更新）

### 5. 宗门
- 玩家创建宗门时的内容辅助（名称/简介/建筑名/功法/技能/入门要求/特殊地图/地图怪物/获取方法）

### 6. 角色
- 当熟练度和某个流派**极高**时，修炼**顿悟**时有概率**创建新的功法**和逐渐**道路**
- 道路：传承 / 开悟 / 飞升 / 渡劫 / 特殊体质
