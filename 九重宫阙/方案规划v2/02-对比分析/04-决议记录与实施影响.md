## D1 寿命机制（问题 1）

### 决议内容
- 离线时间按 **100%** 推进游戏年龄（24 小时 = 游戏 10 年，不打折）
- 离线期间的资源/炼丹/修炼收益按 **100%** 效率结算
- 寿元耗尽 → **坐化转世**

### 实施影响

| 项 | 现状 | 改动 |
|---|---|---|
| 年龄字段 | 无 | character 新增 `age_years`（游戏年，浮点累加）与 `lifespan_years`（寿元上限） |
| 时间引擎 | 无 | 全局时间服务：所有经过时长（在线+离线）按 `现实小时 × 10/24` 游戏年累加 |
| 离线收益 | cultivation.js:59 离线修炼 **0.5 倍**系数 | **移除 0.5 系数**，改为 100%；挂机/采集/炼丹练习同样全额结算 |
| 坐化转世 | 无 | 新增转世流程：清空 境界/修为/等级/装备/功法；保留清单见下方细化项 |
| 寿元曲线 | 无 | ~~9 档草案~~ **已由 D5 增补修订**：凡人 100 → … → 大乘圆满 **100 万年**（不飞升上限），飞升超脱寿数。见 D5 |
| 延寿手段 | 无 | 升级（随境界档提升上限）+ 延寿丹药 + 功法加成 |

### ⚠️ 由此产生的直接推论（需要知晓）
1. **凡人总寿命 = 10 个真实日**（100 年 ÷ 10年/天）。新玩家若不尽快突破炼气（150年=15天）并获取延寿资源，10 天内必坐化
2. **挂机上限 250h ≈ 104 游戏年**：一次满额离线 = 普通人一生。长挂变成「大量收益 vs 大量寿命」的战略选择，延寿丹药因此成为核心强消耗品（天然的变现场景）
3. **新号保护建议**（细化项，待用户确认）：出生自带延寿丹 ×3；前 3 次突破成功率 +20%；转世开局赠送少量启动资源

### 坐化转世保留清单（细化项·建议稿，待确认）
| 保留 | 清空 |
|---|---|
| 熟练度等级（10 级阶梯） | 境界/修为/等级 |
| 成就/图鉴/称号 | 装备/功法（身上+已学） |
| VIP 等级与点券 | 灵石（建议 70% 折损带入） |
| 仓库（建议 50% 物品随机折损） | 灵宠契约（建议保留蛋、清空成体） |
| 图纸收藏 | 洞府（重置为初始） |

## D2 元素/灵根体系（问题 2）

### 决议内容
**7 系战斗元素**：金、木、水、火、土、光明、黑暗。
**6 特殊灵根**：剑、丹、欲、财、至尊、炉鼎——作为流派被动/专属技能/宗门门槛，**不参与基础克制**。
雷、风从战斗元素中移除。

### 实施影响

| 项 | 改动 |
|---|---|
| 克制表 | damage.js 的 `elementEffectiveness` 全表重写：金克木→木克土→土克水→水克火→火克金（循环）；光明↔黑暗互克 1.3x；光暗对五行 1.0 |
| 数据迁移映射 | 旧代码元素 → 新元素：`lightning → 金`、`wind → 木`、`fire → 火`、`water → 水`、`earth → 土`、`holy → 光明`、`dark → 黑暗`（涉及 monsters、maps.element、SKILLS_DATA、player_skills 元素字段） |
| skill.js ELEMENTS 表 | 重写为 7 系（含中文名/克制数组） |
| combat.js 敌人元素 | 8 元素名单改 7 系 |
| 特殊灵根 | 新增字段 `special_root`（剑/丹/欲/财/至尊/炉鼎/无）：提供流派被动、专属技能学习资格、宗门入门判定（如五行山要求 3+ 灵根） |
| 灵根生成 | 注册时生成：五行主灵根（1-5 灵根组合）+ 概率特殊灵根；五行灵石"1-2灵根暴毙/3-5灵根增益"据此判定 |

### 建议克制系数
克 1.3x / 被克 0.7x / 光暗互克 1.3x / 无关 1.0（比现行 1.5/0.5 更平滑，利于平衡）。

### 决议内容
以程序化为主；已有配方库直接复用；部分情况接入 AI；**玩家不是 AI 控制方，游戏（服务端）决定 AI**。

### 实施影响

| 项 | 设计 |
|---|---|
| 权威模型 | AI 调用只发生在服务端（管理后台/生成管线），客户端永远不传 prompt；玩家行为只是「触发条件」（如顿悟概率判定） |
| 生成铁律 | 数值永远程序生成（按品阶模板）；AI 仅填充名称/描述/风味文本 |

## D5 寿命体系增补（2026-09-11 第二轮裁决）

### 决议内容（用户原话）
「随着修为提升寿命增加，从 100 年初始到最多**不飞升上限 100 万年寿命**，然后**战斗受伤也会寿命损失，重伤**」

### 一、寿元曲线修订（替换 D1 原 9 档草案）

| 阶段 | 寿元上限（基础） | 现实时间约合（24h=10年） |
|---|---|---|
| 凡人（出生） | 100 年 | 10 天 |
| 炼气 | 200 年 | 20 天 |
| 筑基 | 500 年 | 50 天 |
| 金丹 | 1,500 年 | 150 天 |
| 元婴 | 5,000 年 | ≈1.4 年 |
| 化神 | 2 万 年 | ≈5.5 年 |
| 渡劫 | 10 万 年 | ≈27 年 |
| 大乘 | 30 万 年 | ≈82 年 |
| **大乘圆满（不飞升上限）** | **100 万 年** | ≈274 年 |
| 飞升 | **超脱寿数**（寿元机制退场，压力源转为上界：飞升门收割等） | — |

- 境界内每升 1 级：+当前境界基础寿元的 1%
- 延寿丹药/功法：基础之上累加，**总上限锁定 100 万年**（不飞升不可突破，丹药边际递减）
- 设计动态：寿命压力集中在**前中期**（凡人→金丹约 5 个月真实时间窗）；后期靠**战斗伤势**维持寿命管理需求

### 二、战斗损寿系统：伤势/重伤（**已定稿**，按用户两项细化裁决）

**模型**：仅重伤事件扣寿 ＋ 伤势积累施压 ＋ 自动调息保护（挂机同等风险）

| 规则 | 设计 |
|---|---|
| 伤势值 | 0-100，战斗中按「承受伤害 ÷ 最大生命」积累；**挂机与手动同系数（同等风险）**；PVP 积累系数 ×2（可调） |
| 伤势效果（**不直接扣寿**） | 轻伤 ≥30：战力 -5%；中伤 ≥60：战力 -15%、修炼 -10%；≥ 阈值（默认 80）：触发**自动调息** |
| 重伤事件（**唯一扣寿来源**） | ① 单场**战败** ② 单场**濒死**（HP<10% 但幸存）→ 扣寿命 = 寿元上限 ×1%（战败 ×2%）；并进入重伤状态：战力 -30%、修炼 -30%，直至疗伤 |
| 自动调息（可配置，默认开） | 伤势 ≥ 玩家设定阈值（默认 80）时，角色**自动停止战斗转入调息**：按时间恢复伤势（每游戏日 -20，洞府中加倍），期间无战斗收益；恢复后自动继续挂机/上次活动 |
| 疗伤恢复 | **疗伤丹**立即清空伤势/解除重伤；洞府静修加速恢复 |
| 死亡衔接 | 重伤扣寿后寿元归零 → 立即坐化转世（衔接 D1） |
| 配置项 | 自动调息开关 + 阈值（玩家设置页）；关闭后重伤风险自负（连续战败 = 连续扣寿，死亡螺旋自担） |

**风险动态**：挂机同等风险 → 不开自动调息 = "敢死队"模式（收益不间断，但连续战败会连续扣寿直至坐化）；开自动调息 = 收益间歇性中断但寿命安全。**延寿丹（进项）+ 疗伤丹（修复）形成双重消耗闭环**。

### 三、实施影响

| 项 | 改动 |
|---|---|
| character 字段 | `injury`（伤势 0-100）、`injury_status`（无/重伤）、`auto_meditate_enabled`（默认 true）、`auto_meditate_threshold`（默认 80） |
| 战斗结算钩子 | combat/dungeon/arena/guild-war 结算后：伤势积累 → 阶梯 debuff → 战败/濒死判定扣寿 |
| 挂机系统 | 伤势达阈值 → 自动调息（暂停刷怪/采集，按游戏日恢复，洞府加倍）→ 恢复后自动续接上次活动 |
| 新丹药类别 | 疗伤丹（清伤势/解除重伤）、大还丹（重伤立即解除+短时免疫）——新增炼丹配方与经济水槽 |
| 寿命 UI | 角色面板：寿命条（当前/上限）+ 伤势条 + 调息状态图标；重伤状态提示 |
| 设置页 | 自动调息开关与阈值配置 |
| 变现联动 | 疗伤丹/大还丹进入商城与套餐；重伤免除可作 VIP 特权之一 |

### 四、细化点裁决记录（2026-09-11 第二轮，已确认）

1. **受伤→寿命损失模型**：✅ 仅重伤事件扣寿（战败/濒死），普通受伤零寿命代价，仅伤势积累施压
2. **挂机风险**：✅ 挂机同等风险（同系数积累伤势）＋ 伤势过重自动调息修正一段时间（可配置开关与阈值，默认开启）
