# 可行性 · 可玩性评审（设计+技术综合视角）

> 评审对象：D1-D5 定稿后的完整玩法闭环。产出日期 2026-09-11。

---

## 一、完整流程可行性 ✅（有条件通过）

**循环自洽性检查**（时间引擎 → 挂机收益 → 伤势积累 → 自动调息 → 寿命消耗 → 突破续命 → 坐化转世 → 传承重开）：链路闭环，无死循环，无收益真空期。

| 维度 | 结论 |
|---|---|
| 技术可行性 | ✅ SQLite + 全局时间服务 + 伤势/寿命数值字段化，均为成熟模式；AI 密钥池+审核池有现成架构 |
| 节奏可行性 | ✅ 实测预估：金丹（1500年）约 1-2 周、化神约 1-2 月、大乘圆满（100万年）约数月——符合长线挂机品类 |
| 数值可行性 | ⚠️ **最大隐性成本**：100 万年寿命跨度、1:1000 四级灵石、10 级熟练度、1-5 纹超品的数值平衡工作量巨大，需专门数值阶段 |
| 运营可行性 | ⚠️ 拍卖行并发防刷、UGC 宗门治理、AI 内容审核人力——三项需要运营配套 |

## 二、可玩性评估

**强点（差异化核心）**：
1. **寿命硬约束**是与其他修仙挂机（想不想修真/一念逍遥等"无死亡"品类）的最大差异——每次突破有真实生存意义，挂机游戏第一次有了"死亡张力"
2. **转世 roguelite 多周目**：灵根 × 流派 × 宗门路线的组合构建（build），二周目有新目标
3. **伤势/调息**制造"带多少药出门"的战前决策，挂机有了主动管理感
4. 生产深度（法痕/器灵/词条）+ AI 生成内容 = 长线追求不枯竭

**风险与对策**：
| 风险 | 对策 |
|---|---|
| 新手 10 天寿命内不理解机制即坐化 → 挫败流失 | 新号保护定稿（出生延寿丹×3+前3次突破+20%）+ 寿命 UI 教学强引导 |
| "怕挂机变老"心理与挂机品类矛盾 | 挂机收益 100% 对冲 + UI 把年龄正面化（年龄=资历=境界门槛） |
| AI 冷启动内容量不足 | 管理端预生成内容库打底，运行时 AI 只做增量 |

## 三、可优化项（建议清单）

1. **PVP 分级伤势**：擂台切磋伤势减半且不触发扣寿，野战/盟战/宗门战全额——防恶意 PVP 扣寿骚扰（重要）
2. **寿命 UI 直译**：显示"约合现实时间"与坐化倒计时，抽象寿数变具体体感
3. **首次坐化仪式化**：做成 AI 剧情大事件（走马灯+传承交接），把挫败转化为叙事高潮
4. **挂机预估**：挂机设置页显示"本次可挂 ≈ X 游戏年"
5. **自动嗑药选项**：疗伤丹优先于调息停摆（可配置）
6. **前期经济体感**：下品灵石为主 + 小额中品做惊喜，避免 1:1000 的遥远感
7. **AI 成本护栏**：预算告警 + 生成缓存 + 每玩家每日触发上限
