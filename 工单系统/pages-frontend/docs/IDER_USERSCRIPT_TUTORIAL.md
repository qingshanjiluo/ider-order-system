# 艾德尔修仙传 · 篡改猴完整使用教程

## 一、安装篡改猴（Tampermonkey）

### 电脑端（Chrome/Edge）

1. 打开浏览器扩展商店：
   - **Chrome**: https://chromewebstore.google.com → 搜索 "Tampermonkey"
   - **Edge**: https://microsoftedge.microsoft.com → 搜索 "Tampermonkey"
2. 点击「获取」或「添加到 Chrome」安装
3. 安装后浏览器右上角会出现 🐵 图标

### 电脑端（Firefox）

1. 打开 https://addons.mozilla.org
2. 搜索 "Tampermonkey"
3. 点击「添加到 Firefox」

### 手机端（Kiwi Browser / Edge Canary）

1. 安装 **Kiwi Browser** (Google Play / App Store)
2. 打开 Kiwi → 地址栏输入 `chrome://extensions/`
3. 打开「开发者模式」(右上角开关)
4. 下载 Tampermonkey CRX 文件 → 拖入浏览器安装
5. **或** 直接打开 https://www.tampermonkey.net 点击安装

---

## 二、安装艾德尔脚本

### 方法 A：一键安装（推荐）

1. 确保已安装篡改猴
2. 打开以下链接：

   ```
   https://ider-order-system.pages.dev/docs/ider_skin_full.user.js
   ```

3. 篡改猴会自动弹出安装页面
4. 点击「安装」

### 方法 B：手动安装

1. 复制上方链接中的全部代码
2. 点击浏览器右上角 🐵 → 「添加新脚本」
3. 删除编辑器里的默认代码
4. **全部粘贴** → `Ctrl+S` 保存

### 方法 C：从工单系统安装

1. 登录工单系统 → https://ider-order-system.pages.dev
2. 进入「皮肤管理」页面
3. 点击「安装脚本」按钮
4. 确认安装

### 检查是否安装成功

1. 打开游戏页面：`https://idlexiuxianzhuan.cn`
2. 按 `F12` 打开开发者工具
3. 切换到 **Console（控制台）** 标签
4. 应该看到如下日志：

   ```
   [皮肤] 已应用工单系统皮肤: ink
   [皮肤inkwash] header 引首 + 印章
   [皮肤inkwash] 导航栏SVG已禁用
   [皮肤inkwash] 命途卷轴装饰已移除
   [账号切换] 账号切换助手 v7.0 已启动
   ```

1. 检查 🐵 图标是否点亮（灰色=禁用）
2. 右键 🐵 → 「管理面板」→ 确认脚本已启用
3. 刷新游戏页面

## 五、常见问题

### Q: 安装后游戏没变化？

- 确认脚本版本 ≥ 5.0（管理面板查看）
- 清理浏览器缓存：`Ctrl+Shift+Del` → 勾选「缓存的图片和文件」
- 重新安装：管理面板 → 删除旧脚本 → 重新安装

### Q: 控制台报错 `Unexpected identifier 'svg'`？

- 这是旧版本（<5.0）的已知问题
- 更新到最新版本即可
- 如果仍有问题，刷新页面重试

### Q: 皮肤效果不对/排列混乱？

- 按 `F12` → Application → Storage → Clear site data
- 重新加载游戏页面
- 如果还不行，在皮肤面板切换回「默认」再切回来

### Q: 如何更新脚本？

- 🐵 → 「管理面板」→ 脚本会自动检查更新
- 或打开安装链接重新安装（自动覆盖旧版）

### Q: 手机怎么用？

- 安卓：安装 Kiwi Browser → 装篡改猴 → 装脚本
- iOS：不支持（Safari 限制）
