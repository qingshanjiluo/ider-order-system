## 1. 系统架构

```
┌───────────────────────────────────────────────────────┐
│              ider_skin_full.user.js                    │
├───────────────────────────────────────────────────────┤
│  ① ICONS 对象 (13 通用 + 3 皮肤专属)                    │
│  ② SKINS 对象 (8 套本地 CSS 后备)                       │
│  ③ 皮肤管理逻辑 (pick/apply/save)                       │
│  ④ API 同步 (fallback+fetch 架构)                       │
│  ⑤ 注入皮肤切换按钮 + 选择面板                           │
│  ⑥ emoji→SVG 替换 (30 处)                               │
│  ❌ layout() DOM 引擎 (未移植)                           │
│  ❌ MutationObserver (未移植)                            │
├───────────────────────────────────────────────────────┤
│              [key].js (Server CSS)                      │
├───────────────────────────────────────────────────────┤
│  ① 8 套完整 CSS (ink/cyber/luxe/magazine/wabi/         │
│     minimal/frost/brutal)                               │
│  ② ink 含 ~85 行完整水墨布局样式                        │
│  ③ cyber/luxe/magazine/frost 含签名装饰                 │
├───────────────────────────────────────────────────────┤
│              inkwash.js (参考文件)                       │
├───────────────────────────────────────────────────────┤
│  ① SVG 图标库 (mount/sword/pouch/bamboo/heart/... )    │
│  ② Phase 1-8 layout() DOM 改造引擎                     │
│  ③ MutationObserver 抵抗 Vue 重渲染                     │
│  ④ 背景装饰注入 (远山/云雾/墨点/飞鸟)                    │
└───────────────────────────────────────────────────────┘
```

### 数据流

```
用户选择皮肤
    │
    ├─→ API /api/skins/css/{key} 获取服务端 CSS
    │     └─→ 成功: 注入 <style data-ider-skin-os>
    │     └─→ 失败: 使用本地 SKINS[key].css (后备)
    │
    └─→ (未来) 触发 layout() DOM 改造引擎
          └─→ 布局重排 + 类标记 + 装饰注入
```

## 5. 页面布局（响应式）

### 5.1 关键布局约定

布局通过 JS `layout()` 引擎执行 DOM 操作 + CSS 配合完成。**当前 `ider_skin_full.user.js` 只有 CSS 注入，没有布局重排 JS。**

### 5.2 inkwash 布局改造 (Phase 1-8)

#### Phase 1: Header → 居中引首卷轴

```
改造前: 横排 [角色名 | 境界 | 灵石:12345 | 按钮]
改造后: 居中竖排
  ┌─────────────────────┐
  │         ╻           │  ← 引首垂线
  │     ┌──────┐        │
  │     │ 朱砂  │        │  ← 印章边框包裹角色名 (cinnabar)
  │     │ 无名  │        │     rotate(-2deg), radius gradient
  │     └──────┘        │
  │   炼气期 · 第七层    │  ← .hdr-info (细字, letter-spacing 0.3em)
  │  ─ ─ ─ ─ ─ ─ ─     │  ← 墨线分割器 (两端小圆点)
  │  灵石:12,345 宗门..  │  ← 资源行
  │  [🖌️] [⚙️]          │  ← SVG 按钮行
  └─────────────────────┘
```

#### Phase 2: 导航栏 → 左竖卷轴 (桌面) / 横排 (移动)

⚠️ **核心响应式策略** — 解决"竖直挡手"问题：

| 断点 | 导航布局 | Tab 方向 | 主内容区 | 侧栏 |
|------|---------|---------|---------|------|
| ≥1024px (桌面) | `fixed; left: 0; top: 50%;` 竖排 | `writing-mode: vertical-rl` | `margin-left: 48px` | 右置 180px |
| 768-1023px (平板) | 顶部横排居中 | `flex-direction: row` | `margin-left: 0` | 右置 |
| <768px (移动) | 顶部横排紧凑 | 水平, `font-size: 11px` | 全宽 | 隐藏/折叠 |

**导航悬停效果**: 墨迹从右向左扩散 (`inkwashSpread` 0.4s)
**激活指示器**: 桌面 → 朱砂右线 `::after` (2px)；移动 → 朱砂底线

## 8. 各皮肤专属设计

### 8.1 水墨修仙 (inkwash)

- **哲学**: 宣纸为底、墨色为骨、朱砂为魂
- **字体**: Ma Shan Zheng (标题/角色名), Noto Serif SC (正文), 字距 0.04em
- **签名**: 印章边框角色名、朱砂左线卡片、墨线填染数值条
- **图标风格**: 笔触质感 1.5px stroke-linecap round
- **适用**: 核心皮肤，布局改造最深入

### 8.2 赛博修仙 (cyber)

- **哲学**: 霓虹光污染、数据流、速度感
- **字体**: Orbitron (标题), Rajdhani (正文)
- **签名**: header 底部 RGB 扫描渐变线动画、水平扫描线背景、40px 网格
- **图标风格**: 几何切割 #00f0ff 霓虹色
- **适用**: 布局不改，仅 CSS 上色

### 8.3 奢华金属 (luxe)

- **哲学**: 鎏金溢彩、浮雕质感
- **字体**: Playfair Display + Noto Serif SC
- **签名**: 底部金线渐变装饰 + 垂直细线背景
- **适用**: 仅 CSS 上色

### 8.4 轻奢杂志 (magazine)

- **哲学**: 编辑式、大留白、克制优雅
- **字体**: Noto Serif SC, uppercase, 字距 2-4px
- **签名**: 水平 40px 指引线背景
- **适用**: 仅 CSS 上色

### 8.5 日式和风 (wabi)

- **哲学**: 侘寂美学、一木一石
- **字体**: Noto Serif JP + STSong
- **signature**: header 底部 ◇ 装饰
- **适用**: 仅 CSS 上色

### 8.6 极简主义 (minimal)

- **哲学**: 少即是多、去装饰化
- **字体**: Inter + Noto Sans SC
- **签名**: 无装饰，纯留白
- **适用**: 仅 CSS 上色

### 8.7 磨砂玻璃态 (frost)

- **哲学**: Apple 风格毛玻璃、通透悬浮
- **字体**: Inter + Noto Sans SC
- **签名**: 顶部辐射渐变 + 呼吸光晕动画
- **特色**: 全界面 `backdrop-filter: blur()`, 大圆角 14-24px
- **适用**: 仅 CSS 上色

### 8.8 粗野主义 (brutal)

- **哲学**: 粗粝不羁、厚边框撞色
- **字体**: Impact/Arial Black, uppercase
- **签名**: 纯黑背景、亮橙强调、8px 阴影偏移
- **风格**: 无圆角、粗 2-4px 边框、`box-shadow` 偏移
- **适用**: 仅 CSS 上色
