# 《仙 九重天阙》游玩全流程指南

## 一、注册与创建角色

### 1.1 注册账号
- 访问 https://zzhxider.cc.cd
- 点击"注册"，输入用户名（3-12字符）、密码、确认密码
- 可选填邮箱用于找回密码
- 勾选"我已阅读并知晓"用户协议

### 1.2 创建角色
- 输入角色名（2-12字符）
- **灵根参悟**：点击"重新参悟"随机生成灵根
  - 天灵根（5%）：单系100，修炼速度×1.5
  - 变异灵根（8%）：单系85-100+变异属性（雷/冰/风/暗/光）
  - 真灵根（30%）：2-3系，每系50-85
  - 伪灵根（57%）：4-5系，每系30-60
- 灵根影响修炼速度、突破成功率、技能效果
- 确认后进入游戏

## 二、新手期（1-120级 炼气期）

### 2.1 核心操作流程
```
地图挂机 → 获取经验和装备 → 背包装备 → 修炼升级 → 循环
```

### 2.2 地图挂机
1. 点击"地图"Tab
2. 选择"人界"地图（推荐从"荒石村"开始）
3. 点击"开始战斗"或开启"自动刷怪"
4. 实时战斗显示：HP/MP条、行动条、战斗日志
5. 胜利获得：经验值、灵石、装备、材料

### 2.3 装备系统
1. 获取装备后前往"背包"
2. 点击装备查看属性对比（绿色=更好，红色=更差）
3. 点击"装备"穿戴到对应栏位
4. 10个装备栏位：武器/头盔/护肩/胸甲/腿甲/护手/戒指/项链/披风/符箓

### 2.4 修炼升级
1. 点击左侧面板"修炼升级"
2. 消耗灵石提升等级
3. 等级提升增加六维属性：力量/体质/根骨/身法/真元/灵力

### 2.5 技能系统
1. 点击"技能"Tab
2. 学习技能需要消耗技能点（升级获得）
3. 装备技能到快捷栏（最多装备3个主动技能）
4. 可设置3套技能预设：挂机/副本/斗法

### 2.6 功法系统
1. 点击"功法"Tab
2. 设置主修功法（影响修炼速度和突破）
3. 设置辅修功法（提供被动加成）

## 三、中期发展（120-200级 筑基→元婴）

### 3.1 境界突破
- **120级突破（筑基）**：
  - 基础成功率15%
  - 使用筑基丹（每颗+20%，最多5颗）
  - 突破失败等级-1
  
- **160级突破（元婴）**：
  - 基础成功率5%
  - 灵根总和>80加成
  - 使用元灵丹（最多4颗）

### 3.2 百艺制造
点击"百艺"Tab，包含5大子系统：

#### 炼丹
- 选择配方 → 放入材料 → 开始炼制
- 品阶：凡品→一品→...→九品
- 丹药效果：回复HP/MP、提升属性、增加突破成功率

#### 炼器
- **锻造**：主材+引灵+催化剂 → 随机品质装备
- **升品**：消耗同阶材料提升装备品质（Q1→Q8）
- **精锻**：重铸装备词缀，可锁定部分词缀
- **神器谱**：特定组合可触发EX品质神兵

#### 制物
- 制作各种消耗品（回城卷、传送符等）

#### 制符
- 制作符箓，装备到符箓栏位提供被动效果

#### 刻阵
- 制作阵法相关道具

### 3.3 洞府系统
点击"洞府"Tab：

#### 采集
- **灵田**：采集草木/液体/皮质材料
- **灵矿**：采集土石/金属/玉质材料
- 每分钟15%概率产出，消耗灵气

#### 阵法
- 5×5阵图拖拽拼阵
- 阵盘（不同形状）+ 阵纹（属性/方向）组合
- 连通阵纹提供触发值，激活主阵盘产生灵石收益
- 流量系统：供给 vs 消耗平衡

### 3.4 宗门系统
点击"宗门"Tab：

#### 拜入宗门
- 10个宗门可选：
  - 正道：太虚剑派（金）、青云丹宗（火）、天音阁（无）
  - 魔道：血煞魔宗（水）、万蛊门（木）、尸傀宗（无）、黑天魔教（暗）、焚天魔宫（火）
  - 联盟：四海散修盟（无）、万界商会（土）

#### 宗门技能
- 基础→中级→高级（需等级和前置功法）
- 消耗宗门贡献学习

#### 宗门任务
- 每日完成获取贡献
- 贡献可用于学习技能、兑换宝库物品

#### 宗门宝库
- 消耗贡献兑换装备和道具

#### 论道殿
- 消耗材料选择其他宗门学习其技能/功法（跨门派）

### 3.5 仙盟系统
点击"仙盟"Tab：

#### 创建/加入仙盟
- 消耗灵石创建仙盟（上限30人）
- 或申请加入已有仙盟

#### 仙盟活动
- **祈福**：消耗灵石抽材料
- **灵池沐浴**：恢复灵气
- **药园采摘**：采集草药
- **顿悟树**：获取顿悟经验
- **捐献**：捐献物资获取贡献

#### 仙盟建筑
- 升级建筑提供各项加成

#### 仙盟仓库
- 共享物资存取
- 可升级仓库容量

#### 宝阁商店
- 消耗仙盟贡献兑换物品

## 四、后期玩法（200级+）

### 4.1 高级境界突破
- **200级突破（炼虚）**：
  - 基础5% + 越级斩杀数(每只+0.3%) + 8万灵石(+10%)
  - 灵根总和加成 + 六维>1500加成

- **240级突破（大乘）**：
  - 基础5% + 副本次数(每次+3%) + 六维>5500加成

- **280级突破（大罗）**：
  - 六维>15000加成 + 拥有技能数(最多15个) + 拥有功法数

### 4.2 命途系统（天赋树）
1. 点击角色面板"命途"入口
2. 7条天赋线：金/木/水/火/土/无(中性)/混元
3. 5层天赋节点(T1-T5)，需前置节点解锁
4. 消耗天赋点解锁，提供各种战斗被动加成
5. T5终极天赋提供独特被动效果

### 4.3 灵宠/妖兽系统
点击"灵宠"Tab：

#### 获取灵宠
- 战斗中有概率捕捉妖兽蛋
- 孵化后获得灵宠

#### 灵宠培养
- **喂养**：消耗食物提升灵宠经验
- **进化**：消耗灵石进化到更高阶
- **出战**：出战后提供属性加成（T1=10%, T2=15%, T3=20%）

#### 灵宠筛选
- 按等级/品阶/攻击/生命排序
- 按元素筛选：火/水/金/木/土/暗

#### 灵宠数据
- 30只灵宠，覆盖6系元素
- 每系3阶（T1→T2→T3）+ Boss级

### 4.4 宗门战争
点击"宗门战争"Tab：

#### 领地系统
- 10块领地，每块有元素/等级/加成描述
- 占领领地提供宗门全体加成：
  - 灵石产出加成
  - 经验加成
  - 攻击/防御加成
  - 全属性加成
  - 暴击/敏捷加成

#### 战争流程
1. 宗门领袖宣战
2. 1小时后自动结算
3. 总战力+随机因子判定胜负
4. 胜方占领领地

#### 赛季制
- 7天一个赛季
- 赛季结束重置领地

#### 实时倒计时
- 进行中的战争显示剩余时间

### 4.5 副本系统
点击"副本"Tab：

#### 副本类型
- 普通副本：单人/组队挑战
- 阵法副本：需要特定阵法配合

#### 组队系统
- 创建队伍
- 加入队伍（输入队伍码）
- 邀请好友
- 踢出成员

#### 自动推进
- 开启后自动战斗推进

### 4.6 斗法/擂台赛
点击"斗法"Tab：

#### 城池斗法
- 选择对手进行PVP对战
- 查看对手装备和属性
- 战斗日志记录

#### 擂台赛
- 报名→分组→淘汰制锦标赛
- 排行榜系统
- 赛季结算

### 4.7 联赛系统
点击"联赛"Tab：

#### 赛季制团队竞技
- 组队报名
- 赛程匹配
- 战报记录
- 联赛商店（消耗联赛积分）

### 4.8 坊市交易所
点击"坊市"Tab：

#### 交易方式
- **挂单出售**：上架物品等待购买
- **求购订单**：发布求购信息
- **装备求购**：指定类型/材质/品质
- **以物易物(Barter)**：物品交换物品

#### 筛选功能
- 分类筛选
- 品质筛选
- 关键词搜索

### 4.9 试炼系统
点击"试炼"Tab：

#### 试炼契约
- 叠加危机词条提升试炼币收益
- 仅支持单人挑战

#### 试炼商店
- 消耗试炼币兑换物品

### 4.10 邮件系统
点击"邮件"Tab：
- 系统邮件列表
- 附件领取
- 一键领取

### 4.11 词典系统
点击"词典"Tab：
- 游戏知识百科
- 状态效果说明
- 掉落规则
- 炼器规则
- 隐藏机制

### 4.12 设置系统
点击"设置"Tab：
- 账号管理
- 数据导入导出
- 设备ID绑定
- 角色删除

## 五、战斗系统详解

### 5.1 战斗属性
- **六维属性**：力量/体质/根骨/身法/真元/灵力
- **战斗属性**：
  - HP/MP
  - 物理攻击（最小/最大）
  - 法术攻击（最小/最大）
  - 物理防御/法术防御
  - 暴击率/暴击伤害
  - 闪避率/命中率

### 5.2 灵根加成
- 金系：破甲/物暴
- 木系：减益/DoT
- 水系：治疗
- 火系：法伤/法暴
- 土系：减伤/防御

### 5.3 灵宠加成
- 出战灵宠提供属性加成
- T1=10%, T2=15%, T3=20%
- 加成类型：HP/攻击/防御/法术攻击

### 5.4 宗门领地加成
- 占领领地提供宗门全体加成
- 加成类型多样：灵石/经验/攻击/防御/全属性/暴击/敏捷

## 八、日常任务建议

### 8.1 每日必做
1. 完成宗门任务（获取贡献）
2. 仙盟活动（祈福/沐浴/采摘/顿悟）
3. 洞府采集（获取材料）

1. 副本挑战（获取高级装备）

3. 联赛比赛（获取联赛积分）

1. 提升境界等级
2. 突破关键等级（120/160/200/240/280）
3. 收集灵宠
4. 占领宗门领地
5. 制造高品质装备

## 十、常见问题

### Q1: 如何快速升级？
A: 选择合适地图挂机，开启自动刷怪，使用经验加成道具。

### Q2: 如何获取高品质装备？
A: 副本掉落、炼器制造、坊市交易、宗门宝库兑换。

### Q3: 如何提升突破成功率？
A: 使用突破丹药、提升灵根品质、积累六维属性、完成特定条件。

### Q4: 如何加入宗门？
A: 点击"宗门"Tab，选择宗门申请加入，等待审批。

### Q5: 如何参与宗门战争？
A: 需要宗门领袖宣战，普通成员可参与防御。
